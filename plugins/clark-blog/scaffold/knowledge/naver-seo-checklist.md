# 네이버 SEO 체크리스트

네이버 블로그 글 검수용 체크리스트입니다. **기준선 = 필수 항목 전부 PASS**. 정량 항목은 `python3 scripts/lint_post.py <final.md> --stage final`이 채점하고, "사람" 항목은 `blog-naver-seo` 스킬이 `seo.md` 채점표에 PASS/수정으로 기록합니다.
숫자(글자수 1700~3500·소제목 4~7·이미지 5장 이상·태그 5~10)는 `knowledge/design-system.md` ④와 같은 값이며, 어긋나면 design-system.md의 lint 블록이 정본입니다. 이 파일은 이랑이 작업 폴더에서 직접 고칩니다.
참고: moai-marketer content-blog/seo-audit 2026 (네이버 C-Rank·D.I.A.+·스마트블록 절을 지게차 학원 블로그에 맞게 다시 씀)

## 필수

| id | 기준 | 왜(네이버 신호) | 측정 |
|---|---|---|---|
| 제목-키워드 | 제목에 핵심 키워드(frontmatter `keyword`)가 들어 있다 | 검색어와 제목 일치가 노출의 첫 관문 | lint `title_keyword` |
| 제목-길이 | 제목 20~40자(공백 포함) | 검색 결과에서 잘리지 않고 의도가 읽히는 길이 | lint `seo_title_length` |
| 제목-위치 | 키워드가 제목 앞 1/3 안에 있다 | 앞쪽 단어가 검색 결과에서 먼저 읽힘 | 사람 |
| 본문-키워드 | 본문에 키워드 3회 이상, 8회 초과 금지 | 주제 적합성은 확보하되 키워드 반복은 저품질 신호 | lint `seo_keyword_body` |
| 소제목-키워드 | `##` 소제목 중 1개 이상에 키워드 | 문서 구조에서 주제를 드러냄(D.I.A.+ 구성 판단) | lint `seo_keyword_h2` |
| 분량 | 본문 1700~3500자 | 체류 시간·정보 충분성 | lint `chars` |
| 소제목 수 | 4~7개 | 훑어 읽기 쉬운 구조, 스마트블록 발췌 단위 | lint `h2_count` |
| 이미지 수 | 5장 이상 | 사진:글 비율, 체류 시간 | lint `images` |
| 이미지 캡션 | 이미지마다 캡션(alt)이 있다 | 이미지 내용을 검색 엔진에 전달 | lint `seo_image_captions` |
| 사진 원본성 | 최근 글과 같은 사진 파일을 재사용하지 않는다 | 반복·복제 콘텐츠 판정 회피 | 사람 (최근 글·`work/variation-log.md`와 대조) |
| 태그 | 5~10개, 핵심 키워드와 지역 키워드 포함 | 관련 검색 연결 | lint `tags_count` + 사람(키워드·지역 포함 여부) |
| 원본성-출처 | 출처 글을 복붙하지 않고, 사실 문장에 출처 각주 | 독창 문서만 상위 노출, 사실 신뢰 | lint `sources`, `placeholder_sources` + 사람(복붙 여부) |
| 원본성-변주 | 날짜·지역명만 바꾼 재발행 금지, 변주 축 기록 | 유사 문서 반복은 품질 하락 | lint `variation` + 사람(최근 5편과 조합 비교) |
| 주제 일관성 | 카테고리 "클라크중장비운전학원"에는 지게차·중장비·자격증·국비 주제만 | C-Rank: 한 분야를 꾸준히 다루는 블로그가 신뢰받음 | 사람 |
| 금칙어 | "실기시험장" 등 금칙어 0건 | 계약 조항 | lint `forbidden` |

기타 형식 검사(`frontmatter`, `h1_once`, `image_paths`)는 업로드 가능 여부 판정용이며 SEO 점수와 별개로 같이 통과해야 합니다.

## 권장

- 도입부 3문장 안에 검색 의도의 답을 요약한다(바로 답을 구하는 독자·AI 요약 대비).
- Q&A 또는 체크리스트 블록을 1개 넣는다.
- 지역 키워드(의정부·양주·동두천·포천·서울북부 중 2개)를 자연스럽게 넣는다.
- 관련글 2~3개를 글 끝에 실제 URL로 건다(lint `related_links`).
- 음영 인용(`>`) 1~2개로 핵심 요약·주의사항을 강조한다.
- 발행 시간대는 이랑이 고른다(자동 결정하지 않음).
- 소제목을 "~방법 / ~순서 / ~비용 / ~기준" 형태로 쓴다(스마트블록에서 질문 답변 단위로 뽑히기 쉬움).
- 글 끝에 핵심만 한 문단으로 요약한다(GEO: AI 검색이 인용하기 좋은 형태).

## 하지 말 것

- 키워드 나열·반복(문장 속에서 부자연스러운 삽입).
- 제목 낚시(본문이 답하지 않는 제목).
- 외부 링크 과다(출처 각주와 관련글 외에는 최소로).
- 같은 이미지를 한 글 안에서 반복하거나 이전 글과 재사용.
- 홍보 문구 과다: 정보성 3 : 홍보 1 이하.
