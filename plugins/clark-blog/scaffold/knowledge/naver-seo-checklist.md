# 네이버 SEO 체크리스트

네이버 블로그 글 검수용 체크리스트입니다. **기준선 = 필수 항목 전부 PASS**. 정량 항목은 `python3 scripts/lint_post.py <draft-v2.md> --stage final`이 채점하고(출처·슬롯 포함본의 SEO 확인), "사람" 항목은 `blog-naver-seo` 스킬이 `seo.md` 채점표에 PASS/수정으로 기록합니다. 업로드본(`final.md`, `build_final.py` 결과)은 메인이 `--stage upload`로 형식(출처 제거·캡션 없음·표지·마무리 블록·소제목 여백)을 다시 봅니다.
숫자는 `knowledge/design-system.md` ④가 정본입니다(v0.3: 글자수 2000~4200·본문 소제목 4~9·이미지 5장 이상·태그 5~10·본문 키워드 3~8회·제목 20~40자 — design-system.md lint 블록 `min_chars=2000 max_chars=4200 min_h2=4 max_h2=9 min_images=5 min_sources=2 tags_min=5 tags_max=10 kw_min_body=3 kw_max_body=8 title_min=20 title_max=40`과 같은 값). 어긋나면 design-system.md의 lint 블록을 따릅니다. `knowledge/design-system.md`가 없으면 lint 기본값(글자수 1500~4000·소제목 4~7 등)이 적용되어 숫자가 다를 수 있습니다. 이 파일은 이랑이 작업 폴더에서 직접 고칩니다.
세는 법(lint와 같음): 글자수·본문 키워드는 `## 📑 목차` 절·해시태그 줄·`ㅤ` 제외, 소제목 수는 `## 📑 목차`·`## 📞 문의` 제외(FAQ 포함), 이미지 수는 표지(`00-cover`)·`학원소개` 제외.
참고: moai-marketer content-blog/seo-audit 2026 (네이버 C-Rank·D.I.A.+·스마트블록 절을 지게차 학원 블로그에 맞게 다시 씀)

## 필수

| id | 기준 | 왜(네이버 신호) | 측정 |
|---|---|---|---|
| 제목-키워드 | 제목에 핵심 키워드(frontmatter `keyword`)가 들어 있다 | 검색어와 제목 일치가 노출의 첫 관문 | lint `title_keyword` |
| 제목-길이 | 제목 20~40자(공백 포함) | 검색 결과에서 잘리지 않고 의도가 읽히는 길이 | lint `seo_title_length` |
| 제목-위치 | 키워드가 제목 앞 1/3 안에 있다 | 앞쪽 단어가 검색 결과에서 먼저 읽힘 | 사람 |
| 제목-지역 | 제목에 이번 글의 제목 지역(`variation.title_region`, 수강생 지역 중 1개) 지역명이 1개 들어 있다. B안도 같은 지역 포함 | 지역 검색 노출, 글마다 지역을 번갈아 유사 제목 반복을 피함 | lint `title_region` + 사람(B안) |
| 본문-키워드 | 본문에 키워드 3회 이상, 8회 초과 금지 | 주제 적합성은 확보하되 키워드 반복은 저품질 신호 | lint `seo_keyword_body` |
| 소제목-키워드 | `##` 소제목 중 1개 이상에 키워드 | 문서 구조에서 주제를 드러냄(D.I.A.+ 구성 판단) | lint `seo_keyword_h2` |
| 분량 | 본문 2000~4200자 | 체류 시간·정보 충분성 | lint `chars` |
| 소제목 수 | 본문 소제목 4~9개 | 훑어 읽기 쉬운 구조, 스마트블록 발췌 단위 | lint `h2_count` |
| 이미지 수 | 5장 이상 | 사진:글 비율, 체류 시간 | lint `images` |
| 톤 | 합니다체 — 해요체 종결(`~해요`·`~예요`·`~죠` 등) 0건 | 블로그 전체 말투 일관성(이랑 결정 2026-10-09) | lint `tone` |
| 출처 형식 | 출처 표기는 문장 끝 `(출처: URL)` 단독 괄호만(조항·시행일은 문장 본문) | 업로드본에서 출처를 손실 없이 기계 제거하기 위한 형식 | lint `source_format` |
| 사진 원본성 | 최근 글과 같은 사진 파일을 재사용하지 않는다(`photos/학원소개.png` 마무리 블록은 예외) | 반복·복제 콘텐츠 판정 회피 | 사람 (최근 글·`work/variation-log.md`와 대조) |
| 태그 | 5~10개, 핵심 키워드와 지역 키워드 포함 | 관련 검색 연결 | lint `tags_count` + 사람(키워드·지역 포함 여부) |
| 원본성-출처 | 출처 글을 복붙하지 않고, 사실 문장에 출처 각주(초안·draft-v2.md 기준. 업로드본은 출처를 지우고 근거는 factcheck.md에 남음) | 독창 문서만 상위 노출, 사실 신뢰 | lint `sources`, `placeholder_sources` + 사람(복붙 여부) |
| 원본성-변주 | 날짜·지역명만 바꾼 재발행 금지, 변주 축 기록 | 유사 문서 반복은 품질 하락 | lint `variation` + 사람(최근 5편과 4축 조합 비교) |
| 주제 일관성 | 카테고리 "클라크중장비운전학원"에는 지게차·중장비·자격증·국비 주제만 | C-Rank: 한 분야를 꾸준히 다루는 블로그가 신뢰받음 | 사람 |
| 금칙어 | "실기시험장" 등 금칙어 0건 | 계약 조항 | lint `forbidden` |

기타 형식 검사(`frontmatter`, `h1_once`, `image_paths`, upload 단계의 `sources_stripped`·`captions_empty`·`cover_file`·`closing_block`·`h2_spacing`)는 업로드 가능 여부 판정용이며 SEO 점수와 별개로 같이 통과해야 합니다.

## 권장

- 도입 2문단 — 상황·질문 다음 문단에 검색 의도의 답을 **굵게** 요약한다(바로 답을 구하는 독자·AI 요약 대비).
- `## 📑 목차`로 본문 소제목을 먼저 보여 주고, 소제목은 키캡 번호(`## 1️⃣ `)로 쓴다.
- 마지막 번호 절에 FAQ(2~4문답, `**Q. …?**` / `A. …`)를 둔다(GEO: AI 검색이 질문 단위로 인용하기 좋은 형태).
- 지역 키워드(의정부·양주·동두천·포천·서울북부 중 2개)를 본문에 자연스럽게 넣는다.
- 관련글 2~3개를 FAQ 뒤, `## 📞 문의 및 수강신청` 앞에 실제 URL로 건다(lint `related_links`).
- 강조는 **굵게** + `💡` 줄로 한다. 음영 인용(`>`)은 0~1개, 비교표는 0~1개.
- 태그는 공백 없는 형태로 쓴다(업로드본 끝 해시태그 줄의 원천).
- 소제목을 "~방법 / ~순서 / ~비용 / ~기준" 형태로 쓴다(스마트블록에서 질문 답변 단위로 뽑히기 쉬움).
- 발행 시간대는 이랑이 고른다(자동 결정하지 않음).

## 하지 말 것

- 키워드 나열·반복(문장 속에서 부자연스러운 삽입).
- 제목 낚시(본문이 답하지 않는 제목), 제목에 지역명 여러 개 나열.
- 외부 링크 과다(출처 각주와 관련글 외에는 최소로).
- 같은 이미지를 한 글 안에서 반복하거나 이전 글과 재사용(`photos/학원소개.png` 마무리 블록 제외).
- 이미지 캡션 쓰기(업로드본은 캡션 없음), 줄글 CTA 단락(마무리는 고정 블록).
- 홍보 문구 과다: 정보성 3 : 홍보 1 이하.
