## ① 글의 목적과 독자

- 목적: 정보성 글로 검색 유입 → 신뢰 → 필요할 때만 상담 연결. 홍보글보다 정보성 글 위주(꼭 지켜야 할 점 2).
- 독자: 의정부, 서울북부, 양주, 동두천, 포천(등록 많은 순)에서 지게차·굴착기 자격을 알아보는 사람.
- 과정: 지게차운전기능사, 3톤미만 지게차, 3톤미만 굴착기, 전동입식·좌식 실무과정. 내일배움카드 국비과정·일반과정.
- 독자가 글에서 얻어야 할 것:
  1. 자격 취득 순서(필기 → 실기 → 면허 발급, 3톤 기준 갈림길)
  2. 비용·지원 방식(국비/일반, 접수처)
  3. 학원을 고를 때 볼 기준

## ② 톤앤매너

규칙:
- 주 종결어미 = **합니다체**(이랑 결정 2026-10-09). 레퍼런스 0에도 해요체가 섞여 있지만(해요체 비율 참고값 33%) 따르지 않는다.

| 구분 | 허용 종결 | 금지 종결 |
|---|---|---|
| 평서 | `~입니다` `~합니다` `~됩니다` `~있습니다` | `~해요` `~예요` `~에요` `~죠` |
| 권유 | `~하세요` `~해 보세요` `~기억해 두세요` | `~볼게요` `~드릴게요` |
| 질문(절 예고·FAQ) | `~까요?` `~나요?` `~ㅂ니까?` `~인가요?` `~세요?` | `~죠?` `~해요?` |

- lint `tone`은 평서문 `요/죠` 종결과 위 목록 밖의 의문문을 센다(규칙 0건).
- 한 문장은 짧게, 한 문단 2~4문장(레퍼런스 2 평균 문장 25자, 자기 글 43자 — 참고값).
- 독자에게 말 걸듯 쓴다: 처지를 먼저 짚고("~하시는 분"), 다음 절로 넘어갈 때 한 문장으로 이어 준다(레퍼런스 2 관찰 메모).
- 도입 2문단: 상황·질문 → **결론 굵게**. "안녕하세요 + 학원 소개"로 시작하지 않는다(자기 글 10편 중 8편이 인사로 시작 — 도입 변주가 안 됨).

- 비용 부담을 줄이고 싶다면 아래 경로도 함께 확인해 보세요. (224409712834)

## ③ 구조 템플릿과 소제목 규칙

**고정 골격**(레퍼런스 0의 겉모습. 표지 슬롯은 초안에 없다 — 표지는 image-plan `00` 행으로 이미지 단계가 만들고 업로드 단계가 맨 앞에 넣는다):

```
# 제목(keyword + title_region 지역명 1개, 20~40자)
도입 2문단(상황/질문 → **결론 굵게**)
## 📑 목차
- 소제목 1 … n (번호 이모지 없이 텍스트만)
---
## 1️⃣ 소제목(검색형 명사구/질문)
본문: 비교표(글당 최대 1개) · ✔️/📖/🚧 이모지 줄(빈 줄로 구분) · 💡 팁 줄 · **핵심 굵게**
![슬롯: 절 내용 요약 장면]()          ← 절 끝(다음 소제목 직전) 1~2장
## 2️⃣ …
## n️⃣ 자주 묻는 질문 (FAQ)              ← 권장(2~4문답, **Q.** 굵게 / A. 문단)
[[관련글: …]] ×2~3                     ← "함께 읽으면 좋은 글"(B'에서 실제 URL)
## 📞 문의 및 수강신청: 031-855-9948   ← 고정 헤딩(초안의 마지막 줄)
(학원소개 이미지·장소·해시태그는 build_final.py가 붙임 — 초안에 쓰지 않음)
```

본문 절 전개 방식(구조 템플릿 4종 — 골격 안 `## 1️⃣`~ 절들을 어떻게 펼칠지, 하나를 골라 ⑦ `structure`에 기록):
- **절차형** — 1단계 → … → n단계 → 놓치기 쉬운 점. 주제: 자격 취득 순서, 원서 접수, 면허 발급.
- **비교형** — A 소개 → B 소개 → 기준 비교표 → 상황별 추천. 주제: 지게차운전기능사 vs 3톤미만, 국비 vs 일반.
- **체크리스트형** — 항목 1~n(소제목마다 1개) → 놓치기 쉬운 것. 주제: 준비물, 실격 사유, 학원 고르는 기준.
- **Q&A형** — 질문형 소제목 n개("~해도 되나요?"). 주제: 자주 묻는 질문, 재발급·적성검사.

소제목 규칙:
- 본문 소제목 수: ④의 **4~9개**(목차·문의 제외, FAQ 포함).
- 형태: `## 1️⃣ ` 키캡 번호 + 검색형 명사구 또는 질문("~방법", "~순서", "~비용", "~할까요?") + 끝 이모지 선택(레퍼런스 0 "5️⃣ 필요서류 체크리스트 📋"). 글 제목을 반복하지 않는다.
- 목차 항목 = 본문 소제목 텍스트(번호 이모지 없이, 같은 순서).
- 소제목당 본문 230~430자(레퍼런스 0 소제목당 330자 → ×0.7~×1.3, 10단위 반올림).
- 소제목 앞 여백: 이미지·구분선 뒤 소제목 앞은 `ㅤ` 2줄, 그 밖은 빈 줄 + `ㅤ` 1줄 — build_final.py가 넣는다(초안에 쓰지 않는다).
- 강조 수단은 **굵게 + 💡 줄**. 음영 인용(`>`)은 0~1개. 비교표는 글당 0~1개.
- FAQ: `**Q. …?**` 줄 → 빈 줄 → `A. …` 문단, 2~4문답.

세는 법(lint와 같음): `chars` = 공백 제외 글자수, `## 📑 목차` 절(다음 `---`까지)·`**#…**` 해시태그 줄·`ㅤ`(U+3164) 제외. `h2_count` = `## ` 소제목, `## 📑 목차`·`## 📞 문의` 제외. `images` = 본문 이미지, 표지(`00-cover.*`)·`학원소개` 제외.
레퍼런스 0 환산(M): 측정표 원값 3,140자·헤딩 11·이미지 9 → 2,971자(목차 112·해시태그 57 제외)·소제목 9·이미지 7·이미지당 424자·굵게 19회(6.4/1000자).

- 본문 글자수(공백 제외): **2000 ~ 4200자** (M 2,971자 → 하한 = max(1500, 100단위 내림(M×0.7 = 2,080)) = 2000, 상한 = max(2000+1000, 100단위 올림(M×1.4 = 4,160)) = 4200. 참고: 레퍼런스 1~4 중앙값 2,462자, 자기 글 중앙값 986자)
- 소제목(`##`) 수: **4 ~ 9개** (M 9 → min_h2 = 4(공식 고정값), max_h2 = max(7, 9) = 9. 참고: 레퍼런스 1~4 중앙값 7, 자기 글 3)
- 이미지 수: **5장 이상**, 권장 장수 = 올림(본문 글자수 ÷ 420) — 2,000자면 5장, 3,000자면 8장, 4,200자면 10장 (하한 = max(3, min_h2 4 + 1, 올림(2,000 ÷ 630) = 4) = 5. 레퍼런스 0 본문 이미지 7)
- 이미지당 글자수: **목표 420자 이하, 상한 630자** (M 424자 → 10단위 420, 상한 = 420×1.5 = 630. 참고: 레퍼런스 3·4 280·253자 — 레퍼런스 0 우선)
- 강조(굵게) 빈도: **1000자당 4~9회**, 핵심 수치·결론·FAQ 질문 줄에만 (M 6.4회 → 내림(×0.7 = 4.5) = 4, 올림(×1.3 = 8.3) = 9. SKILL 굵게 공식은 강조 과다 레퍼런스 1(17.5회)용 상한식이라 기본 허용폭 적용. 참고: 자기 글 중앙값 16.1회)
- 비교표: **글당 0~1개** (레퍼런스 0 표 1개. 표는 붙여넣기 전용이라 업로드 폴백 위험 → 최대 1)
- 음영 인용(`>` 블록): **글당 0~1개** (레퍼런스 0 quotes 0 — 강조는 굵게 + 💡 줄이 맡는다)
- 출처: **2개 이상**, 형식 `(출처: https://…)` 단독 괄호(⑧ 6). 초안·draft-v2.md에만 있고 업로드본에서는 제거된다 (lint 기본값. 지어내기 금지 원칙)
- 태그 수: **5 ~ 10개** (lint 기본값. 레퍼런스 0 해시태그 7개. 본문 끝 해시태그 줄은 같은 tags로 만든다)
- 제목: **20 ~ 40자**, keyword + title_region 지역명 1개. 본문 키워드: **3 ~ 8회** (lint 기본값 = naver-seo-checklist.md)

## ⑤ 이미지 규칙

반드시 지킬 것:
- **텍스트 렌더링 금지**: AI 이미지에 글자 렌더링 금지(간판·자막·숫자 포함). 글자는 본문으로. **예외 = 표지** `images/00-cover.png`(1000×1000 합성): 배경(글자 없는 AI 장면 또는 실사진) 위에 `scripts/make_cover.py`가 제목·브랜드 배지·전화번호를 얹는다. 글자는 중앙 안전 영역 안. AI 배경 자체에는 글자가 없어야 한다.
- **얼굴 클로즈업 금지**: 인물은 뒷모습·원거리·장갑 낀 손·장비 중심.
- **정보성 글 = AI 생성 이미지 허용. 홍보성 글 = 학원 실사진(photos/)만.**
- 사진 재사용 금지: 이전 글에 쓴 실사진 파일·AI 이미지는 다시 쓰지 않는다. **예외: `photos/학원소개.png`는 매 글 마무리 블록(⑥)의 고정 자산**이다.

배치·형식:
- 표지: 초안에 슬롯을 쓰지 않는다. image-plan `00` 행으로 이미지 단계가 만들고, 업로드 단계가 본문 맨 앞에 넣어 대표이미지로 지정한다.
- 본문 이미지: **절 끝(다음 소제목 직전) 1~2장**(레퍼런스 0: 1·3·4·8절 끝, 6절 안).
- 중간 작업 사진: 본문 중간 절에 **지게차 작업 장면 최소 1장**(적재·하역·코스 주행). 이미지 사이 본문이 630자를 넘지 않게 고르게(레퍼런스 4).
- **캡션 없음**: 업로드본 이미지는 `![](경로)`(alt 비움). 슬롯 설명·image-plan alt는 내부용.
- 슬롯 문법: `![슬롯: 장면 설명]()` — 경로는 이미지 단계에서 채운다.
