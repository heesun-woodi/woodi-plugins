## ② 톤앤매너

규칙:
- 주 종결어미 = **해요체**. 사실·수치 문장은 "~입니다"를 섞어도 된다(레퍼런스 2 해요체 95%, 레퍼런스 3 47%(혼합), 자기 글 중앙값 24% — 참고값).
- 한 문장은 짧게, 한 문단 2~4문장(레퍼런스 2 평균 문장 25자, 자기 글 43자 — 참고값).
- 독자에게 말 걸듯 쓴다: 처지를 먼저 짚고("~하시는 분"), 다음 절로 넘어갈 때 한 문장으로 이어 준다(레퍼런스 2 관찰 메모).
- 도입 3문장 안에 검색 의도에 대한 답(결론)을 준다. "안녕하세요 + 학원 소개"로 시작하지 않는다(자기 글 10편 중 8편이 인사로 시작 — 도입 변주가 안 됨).

## ③ 구조 템플릿과 소제목 규칙

구조 템플릿 4종(하나를 골라 ⑦에 기록):
- **절차형** — 도입(결론) → 1단계 → 2단계 → … → n단계 → 놓치기 쉬운 점 → 마무리. 어울리는 주제: 자격 취득 순서, 원서 접수 방법, 면허 발급.
- **비교형** — 도입 → A 소개 → B 소개 → 기준 비교표 → 상황별 추천 → 마무리. 어울리는 주제: 지게차운전기능사 vs 3톤미만, 국비 vs 일반과정.
- **체크리스트형** — 도입 → 항목 1~n(소제목마다 1개) → 놓치기 쉬운 것 → 마무리. 어울리는 주제: 시험 전 준비물, 실기 실격 사유, 학원 고를 때 기준.
- **Q&A형** — 도입 → 질문형 소제목 n개("~해도 되나요?") → 마무리. 어울리는 주제: 자주 묻는 질문, 면허·재발급·적성검사.

소제목 규칙:
- 소제목(`##`) 수: ④의 4~7개.
- 형태: 검색형 명사구 또는 질문("~방법", "~순서", "~비용", "~기준", "~할까요?"). 글 제목을 소제목으로 반복하지 않는다.
- 소제목당 본문 250~470자(레퍼런스 중앙값 364자, 자기 글 중앙값 280자 → ×0.7~×1.3, 10단위 반올림).
- **소제목마다 요약 이미지 1장을 먼저**(레퍼런스 3: 5개 절 전부 소제목 직후 이미지 1장):

```
## 3톤미만 지게차 취득 순서
![슬롯: 교육장에서 강사가 지게차 앞에서 설명하는 원거리 장면]()
이 절에서 다룰 내용을 한 문장으로 먼저 말해요.
```

- 도입부: 3문장 안에 검색 의도에 대한 답 요약(도입부 유형은 ⑦에서 고른다). 음영 인용(`>`)은 ④대로 글당 1~3개, 절 끝 요약·주의사항에만 쓴다(레퍼런스 2 "핵심 정보 요약" 박스 3개).

## ④ 분량과 비율

<!-- 수치 원칙: 이랑 메모가 가리키는 특징 → 그 메모를 남긴 레퍼런스의 값(허용폭 ×0.7~×1.3 또는 리뷰 확정값). 메모가 없는 특징 → 레퍼런스 4개 중앙값. -->

- 본문 글자수(공백 제외): **1700 ~ 3500자** (레퍼런스 중앙값 2,462자, 자기 글 중앙값 986자 → 하한 = max(1500, R×0.7 내림) = 1700, 상한 = max(1700+1000, R×1.4 올림) = 3500)
- 소제목(`##`) 수: **4 ~ 7개** (레퍼런스 소제목(수동) 중앙값 7, 자기 글 3 → 하한 4 = 변주 축 범위·레퍼런스 3 "여러 개", 상한 = max(7, 7) = 7)
- 이미지 수: **5장 이상**, 권장 장수 = 올림(본문 글자수 ÷ 280) — 1,700자면 7장, 2,600자면 10장, 3,500자면 13장 (메모 출처 레퍼런스 3·4 → 하한 = 올림(글자수 하한 1,700 ÷ 상한 420) = 5 = max(3, 소제목 하한 4 + 1))
- 이미지당 글자수: **목표 280자 이하, 상한 420자** (메모 "사진:글 비율"을 남긴 레퍼런스 3 280자·레퍼런스 4 253자 → 목표 = 큰 값 280, 상한 = 280×1.5 = 420. 참고: 4개 중앙값 539자, 자기 글 178자)
- 강조(굵게) 빈도: **1000자당 6~12회**, 핵심 수치·결론·독자 질문 줄에만 (메모 "강조 굵게"를 남긴 레퍼런스 1 17.5회 → 상한 = 17.5×0.7 = 12, 하한 = 레퍼런스 4 5.9회 올림 = 6. 참고: 4개 중앙값 3.6회, 자기 글 16.1회)
- 음영 인용(`>` 블록): **글당 1~3개**, 절 끝 요약·주의사항용. 소제목을 인용구로 만들지 않는다(소제목은 `##`) (레퍼런스 1 "음영" = 측정 불가(배경색 미추출) → naver-blog-cli가 지원하는 `>` 인용으로 대체. 개수 근거 = 레퍼런스 2 절 끝 요약 박스 3개. 자기 글 2.5개)
- 출처 각주: **2개 이상**, 형식 `출처: https://…` (lint 기본값. 지어내기 금지 원칙)
- 태그 수: **5 ~ 10개** (lint 기본값. naver-seo-checklist.md에 태그 기준이 생기면 그 값)

## ⑤ 이미지 규칙

반드시 지킬 것:
- **텍스트 렌더링 금지**: AI 이미지에 글자 렌더링 금지(간판·자막·숫자 포함). 글자는 본문·캡션으로.
- **얼굴 클로즈업 금지**: 인물은 뒷모습·원거리·장갑 낀 손·장비 중심.
- **정보성 글 = AI 생성 이미지 허용. 홍보성 글 = 학원 실사진(photos/)만.**
- 사진 재사용 금지: 이전 글에 쓴 실사진 파일·AI 이미지는 다시 쓰지 않는다.

측정값 기반:
- 배치: 커버 1장 + 소제목마다 요약 이미지 1장(③, 레퍼런스 3).
- 중간 작업 사진: 본문 중간 절에 **지게차 작업 장면 최소 1장**(적재·하역·코스 주행). 이미지 사이 본문이 420자를 넘지 않게 고르게 분산(레퍼런스 4: 이미지 10장이 소제목 9개마다 1장씩 고르게).
- 캡션: 이미지마다 한 줄 캡션(무엇을 보여주는지).
- 슬롯 문법: `![슬롯: 장면 설명]()` — 경로는 이미지 단계에서 채운다.
