# 주장 유형별 조회처·질의 방법

조회처·접근성의 정본은 작업 폴더 `knowledge/law-sources.md`다. 이 표는 그 기록(2026-10-06 curl 실측)을 주장 유형별로 다시 묶은 것이고, 둘이 다르면 `law-sources.md`를 따른다.
공통 명령: `curl -sL -A "Mozilla/5.0" --max-time 20 "<URL>"` (WebFetch 실패 시 curl 재시도). 응답은 `T=$(mktemp -d)` 임시 디렉터리에 저장해 grep한다.

### 접근성 요약 (law-sources.md 기준)

- 본문 가능: law.go.kr DRF API(법·시행령·시행규칙), 큐넷 탭 조각 `crf00503s01`·`crf00503s02`, 큐넷 월간 일정 `crf021…crf02103`, 고용노동부 `/index.do`, 국민신문고 `/index.jsp`, 한국산업인력공단(메뉴 수준).
- 껍데기만: law.go.kr 사람용 상세 `https://www.law.go.kr/법령/…`(독자용 링크로만), 큐넷 종목 상세 `crf005.do?id=crf00503…`(탭 조각을 써야 함), 큐넷 메인, 고용24 훈련과정 상세 목록.
- 쿠키 필요: 국토교통부(루트는 307 루프).

## 2. 법령 조문 찾는 요령 (DRF XML)

1. **현행 MST부터**: `lawSearch.do?…&query=건설기계관리법` 응답의 `<law>` 항목에서 `<법령명한글>`·`<법령일련번호>`·`<시행일자>`·`<현행연혁코드>현행</현행연혁코드>`를 읽는다.
   2026-10-06 실측: 건설기계관리법 MST 283763(시행 2026-08-28), 시행령 MST 284659(시행 2026-03-24), 시행규칙 MST 285023(시행 2026-03-24). MST는 개정되면 바뀌므로 매번 검색한다.
2. **`LM=` 호출 주의**: `lawService.do?…&LM=건설기계관리법` 은 2026-10-06 실측에서 `<시행일자>20270228`(2026-02-27 공포, **아직 시행 전**) 판본을 돌려줬다. 응답 `<기본정보>`의 `<시행일자>`가 오늘 이후면 그 판본으로 판정하지 말고 현행 MST로 다시 받는다. (`law-sources.md`는 LM을 "현행 본문"으로 적고 있으나 실측과 다르다 — 이랑/메인 확인 필요.)
3. **조문 찾기**: 조문은 `<조문단위>`마다 `<조문번호>`·`<조문가지번호>`(예: 제83조의2 → 83/2)·`<조문제목>`·`<조문내용>`·`<항>`/`<호>`가 있다. `<조문여부>조문</조문여부>`인 것만 본다(`전문`은 장·절 제목).
   ```bash
   T=$(mktemp -d)
   curl -sL -A "Mozilla/5.0" --max-time 40 "https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=285023&type=XML" -o "$T/rule.xml"
   grep -o '<조문제목><!\[CDATA\[[^]]*' "$T/rule.xml" | sed 's/.*CDATA\[//' | grep -n '면허\|소형\|적성\|교육'   # 제목·내용은 CDATA로 감싸져 있다
   python3 - "$T/rule.xml" 81 <<'EOF'
   import sys, xml.etree.ElementTree as ET
   root = ET.parse(sys.argv[1]).getroot()
   for u in root.iter('조문단위'):
       if u.findtext('조문번호') == sys.argv[2] and u.findtext('조문여부') == '조문' and not u.findtext('조문가지번호'):
           print(' '.join(t.strip() for t in u.itertext() if t.strip()))
   EOF
   ```
4. **별표**: 교육 시간·면허 종류 같은 표는 조문이 아니라 `<별표단위>`(`<별표번호>0020</별표번호>`, `<별표제목>`, `<별표내용>`)에 있다. `<별표내용>`은 괘선 문자 표라 grep으로 키워드 줄을 찾는다.
5. 인용 형식: `"<조문 원문 1~2줄>" — 건설기계관리법 시행규칙 제73조제2항제3호(시행 2026-03-24) <MST URL>`.

## 3. 큐넷 종목 탭 읽는 요령 (지게차운전기능사 jmCd=7875)

- 종목코드는 **7875**. (7910은 한식조리기능사, 7785는 3D프린터운용기능사 — 틀리기 쉽다.)
- 응답 HTML에서 태그를 지우고 공백을 정리한 뒤 키워드 주변을 읽는다:
  ```bash
  curl -sL -A "Mozilla/5.0" --max-time 20 "https://www.q-net.or.kr/crf005.do?id=crf00503s02&gSite=Q&gId=&jmCd=7875" \
    | python3 -c "import sys,re;t=re.sub(r'<[^>]+>',' ',sys.stdin.read());t=re.sub(r'\s+',' ',t);i=t.find('수수료 안내표');print(t[i:i+120])"
  ```
- `crf00503s02`: `수수료 안내표 필기 실기 14,500원 25,200원`, 출제기준 `지게차운전기능사 (2025.1.1 ~ 2027.12.31)`, 시험일정 표는 `시험 일정이 없습니다`.
- `crf00503s01`: `종목별 검정현황` 표 — `연도 필기(응시 합격 합격률) 실기(응시 합격 합격률)` 순. 2026-10-06 실측 2025년: 필기 110,316명 응시·81,152명 합격·73.6%, 실기 126,757명 응시·60,745명 합격·47.9%.
- 숫자는 조회 일자를 같이 적고, 초안에 기준 시점이 없으면 시점확인으로 판정한다.

## 4. 자주 틀리는 포인트

각 항목은 근거를 직접 열어 확인한 것만 적었다(2026-10-06 조회). "확인 필요"로 표시한 부분은 단정하지 않는다.

1. **지게차운전기능사 ≠ 3톤 미만 지게차 면허.** 3톤 미만 지게차는 "소형건설기계"로, 시·도지사가 지정한 교육기관의 교육 이수가 국가기술자격 취득을 **대신한다**(시험 없음). 3톤 이상은 국가기술자격(지게차운전기능사) + 적성검사가 필요.
   근거: 건설기계관리법 제26조제3항·제4항 / 시행규칙 제73조제2항제3호 "3톤 미만의 지게차". (별표 20 비고 6의 "실기시험 통과"는 3톤 미만 타워크레인에만 해당.)
2. **3톤 미만 지게차 교육 시간은 이론 6시간 + 조종실습 6시간.** 이론 2+2+2시간(기관·전기·작업장치 / 유압 일반 / 관리법규·도로통행방법) + 실습 6시간, "50분을 1시간으로", 실습은 1일 4시간 초과 금지. → "하루 만에 끝" 같은 단정은 FAIL 후보.
   근거: 시행규칙 별표 20(제74조제4항 관련) 및 비고 2·3.
3. **지게차의 "3톤"은 자체중량이 아니라 인양능력(들어 올리는 무게) 기준.** 굴착기·로더·불도저는 자체중량 기준이라 섞어 쓰면 틀린다.
   근거: 시행규칙 별표 20 비고 4 "지게차의 규격은 인양능력으로 하며".
4. **3톤 미만 지게차 면허는 자동차운전면허가 있어야 한다.** "운전면허 없어도 된다"는 FAIL.
   근거: 시행규칙 제73조제3항, 별표 21 비고 2(「도로교통법 시행규칙」 제53조에 적합한 종류의 자동차운전면허). 구체적으로 어떤 종류(1종 보통 등)인지는 도로교통법 시행규칙 제53조를 열어 보지 않았으므로 **확인 필요** — 초안이 면허 종류를 특정하면 그 조문을 열어 판정한다.
5. **자격증을 땄다고 바로 조종할 수 있는 게 아니다.** 건설기계를 조종하려면 시장·군수·구청장에게 건설기계조종사면허를 받아야 하고, 그 전제가 기술자격 취득 + 적성검사 합격이다.
   근거: 건설기계관리법 제26조제1항·제3항.
6. **정기적성검사는 10년마다(65세 이상은 5년마다).** 면허 받은 날 다음 날부터 기산해 10년(5년)이 되는 해의 1월 1일~12월 31일 사이에 받는다. "면허는 평생 유효/갱신 없음"은 FAIL.
   근거: 시행규칙 제81조제1항·제2항, 법 제29조.
7. **면허 취득 후 안전교육등이 있다.** 최초는 면허를 최초로 받은 날부터 3년이 되는 해(1월 1일~12월 31일), 이후 마지막 교육일부터 3년이 되는 해. 교육 방법·시간은 별표 22의2 — 이 별표의 시간 수치는 이번 검토에서 열지 않았으므로 **확인 필요**.
   근거: 시행규칙 제83조제1항·제3항, 법 제31조.
8. **다른 소형건설기계 이론을 이미 이수했거나 면허가 있으면 이론교육 면제.** 예: 3톤 미만 굴착기 이수자가 3톤 미만 지게차를 추가할 때 이론 면제(실습만).
   근거: 시행규칙 별표 20 비고 5.
9. **큐넷 지게차 종목 탭에는 정기 시험 일정이 없다.** `시험 일정이 없습니다`가 곧 "상시시험"이라는 뜻인지는 이 응답만으로 단정할 수 없다 → 상시 시행 여부·회차 일정은 **확인 필요**(시점확인 + 이랑 확인).
   근거: 큐넷 `crf00503s02`(jmCd=7875), `law-sources.md` 접근성 기록.
10. **수수료·합격률은 해마다 바뀐다.** 2026-10-06 기준 필기 14,500원·실기 25,200원, 2025년 실기 합격률 47.9%. 기준 시점 없는 수치는 시점확인.
    근거: 큐넷 `crf00503s02`·`crf00503s01`(jmCd=7875).
11. **국비(내일배움카드) 지원 금액·자부담 비율은 curl로 확인되지 않는다.** 고용24 훈련과정 응답에 과정별 지원 조건이 없다(Task 4 실측). 금액·비율·"전액 무료" 단정은 출처필요, 제도 언급만 있으면 시점확인 + 이랑 확인. 구체 수치는 **확인 필요**.
    근거: `law-sources.md` 접근성 기록(고용24 훈련 통합검색).
12. **학원 = 시험 장소라는 표현은 사실과 무관하게 금지(계약 조항).** 금칙어 목록은 `knowledge/academy-profile.md`. fact-checker는 FAIL로 표시하고 문장 삭제를 제안한다.
    근거: `knowledge/academy-profile.md` "꼭 지켜야 할 점" 1번.
