# 고정 골격·본문 전개·도입부 예문·마무리 블록 (blog-draft-writer 전용)

`knowledge/design-system.md` ③(고정 골격·본문 전개 방식 4종·소제목 규칙)·⑥(마무리 고정 블록)·⑦(변주 축)을 글로 옮길 때 쓰는 뼈대와 예문이다.
**정본은 작업 폴더 `knowledge/design-system.md`** — 이 파일과 다르면 그쪽을 따른다(이랑이 작업 폴더에서 고친다). 숫자도 design-system.md ④가 정본이며, 아래 숫자는 v0.3 값이다.

- 아래 예문은 **모양 견본**이다. 문장을 그대로 복사하지 않는다(⑧ 4 복붙 금지 — 이 예문도 포함). 글마다 주제·독자 처지에 맞게 새로 쓴다.
- 예문은 모두 **합니다체**다(②). 평서문의 `~해요`·`~예요`·`~죠` 종결은 lint `tone`이 FAIL로 센다. 의문문은 끝이 `~까요?`·`~나요?`·`~ㅂ니까?/~습니까?`·`~인가요?`·`~세요?`면 된다(`~죠?`·`~해요?` 등은 lint `tone` FAIL).
- 예문에는 일부러 수치·일정·금액을 넣지 않았다. `<n>`, `<URL>`, `<연도>`처럼 꺾쇠로 둔 자리는 `research.md`에 출처 URL이 있는 사실로만 채운다. 채울 출처가 없으면 그 문장을 쓰지 않는다. 출처는 문장 끝 `(출처: <URL>)` 단독 괄호, 조항·시행일은 문장 본문에 쓴다(⑧ 6). `[출처](URL)` 링크형은 쓰지 않는다.
- 본문 소제목 4~9개(목차·문의 제외, FAQ 포함), 소제목당 본문 230~430자, 이미지 슬롯 `![슬롯: …]()`은 **절 끝(다음 소제목 직전)** 1~2장(③·⑤). 표지 슬롯은 쓰지 않는다(표지는 이미지 단계의 image-plan `00` 행).

## 1. 고정 골격과 본문 전개 방식 4종

모든 글은 같은 겉모습(③ 고정 골격)을 쓴다: `# 제목` → 도입 2문단 → `## 📑 목차` → `---` → `## 1️⃣`…`## n️⃣` 번호 절(마지막은 FAQ 권장) → `[[관련글: …]]` 2~3줄 → `## 📞 문의 및 수강신청: 031-855-9948`(마지막 줄).
전개 방식 4종(절차·비교·체크리스트·Q&A)은 이 번호 절들을 **어떻게 펼칠지**만 정한다 — 하나를 골라 ⑦ `structure`에 기록한다.

- 목차 항목 = 번호 절 소제목 텍스트(번호·끝 이모지 없이, 같은 순서, FAQ 포함). 목록 뒤 빈 줄 → `---`.
- 이모지 줄(✔️·📖·🚧)은 한 줄 = 한 항목, 줄 사이 빈 줄. `💡` 줄은 절마다 0~1개. 비교표는 글당 0~1개, 표 칸의 수치 근거는 표 바로 아래 문장에 `(출처: URL)`로 단다. 음영 인용 `>`는 글당 0~1개.
- `## 📞` 뒤(학원소개 이미지·장소 카드·해시태그)와 소제목 앞 `ㅤ` 여백은 쓰지 않는다 — `build_final.py`가 붙인다(3절).
- 위 예시는 모양 견본이라 짧다. 실제 글은 절마다 230~430자, 전체 2000~4200자, 이미지 5장 이상(④)이다.

### 1-1. 절차형

- 흐름: 1단계 → 2단계 → … → 놓치기 쉬운 점 → FAQ
- 어울리는 검색 의도: **자격증 취득 절차**, **시험 일정·접수**, **면허 종류·갱신**(발급 순서)
- 번호 절 예시: 1-0 골격 예시 참고. 마지막 단계 뒤에 `## n️⃣ 처음 준비할 때 놓치기 쉬운 점 🚧`을 둘 수 있다.

### 1-2. 비교형

- 흐름: A 소개 → B 소개 → 기준 비교표 → 상황별 추천 → FAQ
- 어울리는 검색 의도: **면허 종류·갱신**(지게차운전기능사 vs 3톤미만 지게차), **국비·내일배움카드**(국비과정 vs 일반과정), **취업·실무**
- 소제목 뼈대 예시(주제: 지게차운전기능사와 3톤미만 지게차 중 무엇을 딸까)

```markdown
## 1️⃣ 지게차운전기능사는 어떤 자격일까요?
## 2️⃣ 3톤미만 지게차 면허는 어떻게 다를까요?
## 3️⃣ 두 자격 비교 기준 한눈에 보기 📊      ← 표 1개(기준: 취득 방법·운전 가능 범위·준비 기간 — 값은 법령 출처로만)
## 4️⃣ 상황별로 고르는 기준
## 5️⃣ 자주 묻는 질문 (FAQ)
```

비교표의 칸은 법령(law.go.kr)·큐넷 출처로 채운다. 출처가 없는 칸은 "큐넷에서 확인"처럼 비워 둔다 — 추측으로 채우지 않는다. 표가 이미 하나 있으면 나머지 비교는 ✔️ 줄로 쓴다(표는 글당 최대 1개).

### 1-3. 체크리스트형

- 흐름: 항목 1~n(소제목마다 1개) → 놓치기 쉬운 것 → FAQ
- 어울리는 검색 의도: **시험 일정·접수**(시험 전 준비물), **안전교육**, **취업·실무**(학원 고를 때 기준)
- 소제목 뼈대 예시(주제: 지게차 학원 고를 때 볼 기준)

```markdown
## 1️⃣ 교육용 장비 관리 상태 확인 기준
## 2️⃣ 연습 시간을 넉넉히 주는지 확인하는 방법
## 3️⃣ 국비과정·일반과정 둘 다 있는지 보는 기준
## 4️⃣ 집에서 다니기 편한 거리인지 따져 보는 방법
## 5️⃣ 상담 때 꼭 물어볼 것 ✅
## 6️⃣ 자주 묻는 질문 (FAQ)
```

항목 소제목은 "~기준 / ~방법 / ~확인"으로 끝내 스마트블록에서 질문 단위로 뽑히게 한다. 각 절 안에서 확인 항목은 ✔️ 줄로 쓴다.

### 1-4. Q&A형

- 흐름: 질문형 소제목 n개 → FAQ(짧은 질문 묶음)
- 어울리는 검색 의도: **면허 종류·갱신**(적성검사·재발급), **국비·내일배움카드**(자주 묻는 질문), **안전교육**
- 소제목 뼈대 예시(주제: 지게차 면허 자주 묻는 질문)

```markdown
## 1️⃣ 필기에 합격하면 언제까지 유효할까요?
## 2️⃣ 자격증만 있으면 바로 지게차를 몰 수 있을까요?
## 3️⃣ 면허를 잃어버리면 어디서 재발급할까요?
## 4️⃣ 내일배움카드로 수강할 수 있을까요?
## 5️⃣ 자주 묻는 질문 (FAQ)
```

답은 소제목 아래 첫 문장에 바로 준다. 근거가 법령이면 조문 번호·시행일을 문장 본문에 쓰고 `(출처: <URL>)`를 그 문장 끝에 붙인다. 질문형 소제목·FAQ 질문의 끝은 `~까요?`·`~나요?`·`~ㅂ니까?/~습니까?`·`~인가요?`·`~세요?` 중 하나로 쓴다(`~죠?`·`~해요?`는 FAQ Q 줄에서 lint `tone` FAIL).

## 2. 도입부 유형 4종 — 예문(도입 2문단)

도입은 2문단이다(②·③): 1문단 = 상황·질문, 2문단 = **결론 굵게**. "안녕하세요 + 학원 소개"로 시작하지 않는다.

| 유형 | 언제 | 예문(1문단 / 2문단) |
|---|---|---|
| 질문 | 독자가 같은 질문을 검색하고 들어올 때 | 지게차 자격증, 필기부터 봐야 할지 실기부터 봐야 할지 헷갈리시는 분이 많습니다. 단계마다 놓치기 쉬운 점이 있어 순서를 먼저 잡아 두면 편합니다. / 결론부터 말씀드리면, **순서는 필기 → 실기 → 면허 발급**입니다. |
| 상황 | 독자의 처지(이직·첫 취업·현장 배치)를 그릴 수 있을 때 | 물류창고 면접에서 "지게차 면허 있으세요?"라는 질문을 받고 이 글을 찾으셨다면 잘 오셨습니다. 준비 순서만 알면 생각보다 복잡하지 않습니다. / 지금 하실 일은 하나입니다. **먼저 필기 시험 일정부터 확인하세요.** |
| 통계 | 큐넷 검정현황처럼 출처 있는 수치가 있을 때 | `<연도>`년 큐넷 검정현황을 보면 지게차운전기능사 실기 합격률은 `<n>`%입니다(출처: https://www.q-net.or.kr/crf005.do?id=crf00503s01&gSite=Q&gId=&jmCd=7875). / 그래서 이 글은 **실기 준비에 집중**해 정리합니다. |
| 오해 바로잡기 | 흔한 착각이 검색어에 묻어 있을 때 | 지게차 자격증만 따면 바로 현장에서 운전할 수 있다고 생각하기 쉽습니다. / 결론부터 말씀드리면, **자격 취득 뒤 면허 발급 절차가 한 단계 더 있습니다.** |

통계형은 `<n>`·`<연도>`를 `research.md`에 적은 실제 값으로만 채운다. 출처 수치가 없으면 통계형을 고르지 않는다.

## 3. 마무리 고정 블록(빌더가 붙임)

줄글 CTA 단락은 쓰지 않는다(⑥ — 이랑 피드백 2026-10-09). 고를 마무리 유형도 없다(`cta` 축 폐지). 글 끝 순서는 고정이다.

| 3 | `## 📞 문의 및 수강신청: 031-855-9948` — 고정 헤딩, 초안의 마지막 줄 | writer(B) |
| 4 | `![](<작업 폴더 절대경로>/photos/학원소개.png)` — 학원명·연락처·주소는 이 이미지가 맡는다 | `build_final.py` |
