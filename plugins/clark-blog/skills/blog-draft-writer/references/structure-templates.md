# 구조 템플릿·도입부·CTA 예문 (blog-draft-writer 전용)

`knowledge/design-system.md` ③(구조 템플릿 4종·소제목 규칙)·⑥(마무리)·⑦(변주 축)을 글로 옮길 때 쓰는 뼈대와 예문이다.
**정본은 작업 폴더 `knowledge/design-system.md`** — 이 파일과 다르면 그쪽을 따른다(이랑이 작업 폴더에서 고친다).

- 아래 예문은 **모양 견본**이다. 문장을 그대로 복사하지 않는다(⑧ 4 복붙 금지 — 이 예문도 포함). 글마다 주제·독자 처지에 맞게 새로 쓴다.
- 예문에는 일부러 수치·일정·금액을 넣지 않았다. `<n>`, `<URL>`, `<연도>`처럼 꺾쇠로 둔 자리는 `research.md`에 출처 URL이 있는 사실로만 채운다. 채울 출처가 없으면 그 문장을 쓰지 않는다.
- 소제목 수는 4~7개(④), 각 소제목 바로 아래 첫 줄은 요약 이미지 슬롯 `![슬롯: …]()`(③·⑤), 소제목당 본문 250~470자.

## 1. 구조 템플릿 4종

### 1-1. 절차형

- 흐름: 도입(결론) → 1단계 → 2단계 → … → 놓치기 쉬운 점 → 마무리(관련글 → CTA)
- 어울리는 검색 의도: **자격증 취득 절차**, **시험 일정·접수**, **면허 종류·갱신**(발급 순서)
- 소제목 뼈대 예시(주제: 지게차운전기능사를 처음 준비하는 순서)

```markdown
# 지게차운전기능사 준비 순서, 필기부터 면허까지 (의정부·양주)
![슬롯: 이른 아침 교육장 전경, 지게차 여러 대가 나란히 서 있는 원거리 장면]()
도입 3문장 — 결론(순서 요약) 먼저.

## 지게차운전기능사 필기 준비 방법
![슬롯: 책상 위 문제집과 연필, 글자가 보이지 않게 흐린 장면]()
문제은행식 필기를 기출 반복으로 준비하는 이유.

## 실기 원서 접수 순서
![슬롯: 노트북 화면을 보는 수강생의 뒷모습, 화면 글자는 흐림]()
큐넷 접수 흐름(일정은 출처와 기준 시점을 붙여서만).

## 실기 코스 연습 순서
![슬롯: 코스를 천천히 주행하는 지게차를 멀리서 본 장면]()
전진·후진·적재 순으로 익히는 흐름.

## 합격 뒤 면허 발급 절차
![슬롯: 서류 봉투와 신분증 실루엣, 글자 없는 추상 장면]()
자격증과 건설기계조종사면허(실제로 장비를 몰 수 있는 면허)의 차이.

## 처음 준비할 때 놓치기 쉬운 점
![슬롯: 안전모와 장갑을 챙기는 손 클로즈업]()
> 절 끝 요약 한 줄(음영 인용).
```

### 1-2. 비교형

- 흐름: 도입 → A 소개 → B 소개 → 기준 비교표 → 상황별 추천 → 마무리
- 어울리는 검색 의도: **면허 종류·갱신**(지게차운전기능사 vs 3톤미만 지게차), **국비·내일배움카드**(국비과정 vs 일반과정), **취업·실무**
- 소제목 뼈대 예시(주제: 지게차운전기능사와 3톤미만 지게차 중 무엇을 딸까)

```markdown
## 지게차운전기능사는 어떤 자격일까요?
## 3톤미만 지게차 면허는 어떻게 다를까요?
## 두 자격 비교 기준 한눈에 보기        ← 표 1개(기준: 취득 방법·운전 가능 범위·준비 기간 — 값은 법령 출처로만)
## 상황별로 고르는 기준
## 고르기 전에 확인할 것
```

비교표의 칸은 법령(law.go.kr)·큐넷 출처로 채운다. 출처가 없는 칸은 "큐넷에서 확인"처럼 비워 둔다 — 추측으로 채우지 않는다.

### 1-3. 체크리스트형

- 흐름: 도입 → 항목 1~n(소제목마다 1개) → 놓치기 쉬운 것 → 마무리
- 어울리는 검색 의도: **시험 일정·접수**(시험 전 준비물), **안전교육**, **취업·실무**(학원 고를 때 기준)
- 소제목 뼈대 예시(주제: 지게차 학원 고를 때 볼 기준)

```markdown
## 교육용 장비 관리 상태 확인 기준
## 연습 시간을 넉넉히 주는지 확인하는 방법
## 국비과정·일반과정 둘 다 있는지 보는 기준
## 집에서 다니기 편한 거리인지 따져 보는 방법
## 상담 때 꼭 물어볼 것
```

항목 소제목은 "~기준 / ~방법 / ~확인"으로 끝내 스마트블록에서 질문 단위로 뽑히게 한다. 마지막 절이나 도입 직후에 체크리스트 블록(`- ` 목록) 1개를 둔다.

### 1-4. Q&A형

- 흐름: 도입 → 질문형 소제목 n개 → 마무리
- 어울리는 검색 의도: **면허 종류·갱신**(적성검사·재발급), **국비·내일배움카드**(자주 묻는 질문), **안전교육**
- 소제목 뼈대 예시(주제: 지게차 면허 자주 묻는 질문)

```markdown
## 운전면허가 없어도 지게차 자격을 딸 수 있나요?
## 필기에 합격하면 언제까지 유효한가요?
## 자격증만 있으면 바로 지게차를 몰 수 있나요?
## 면허를 잃어버리면 어디서 재발급하나요?
## 내일배움카드로 수강할 수 있나요?
```

답은 소제목 아래 첫 문장(이미지 슬롯 다음 줄)에 바로 준다. 근거가 법령이면 조문 번호와 `(출처: <URL>)`를 그 문장 끝에 붙인다.

## 2. 도입부 유형 4종 — 예문

도입 3문장 안에 검색 의도의 답을 준다(②). "안녕하세요 + 학원 소개"로 시작하지 않는다.

| 유형 | 언제 | 예문 |
|---|---|---|
| 질문 | 독자가 같은 질문을 검색하고 들어올 때 | 지게차 자격증, 필기부터 봐야 할지 실기부터 봐야 할지 헷갈리시죠? 결론부터 말씀드리면 순서는 필기 → 실기 → 면허 발급이에요. 단계마다 놓치기 쉬운 점을 차례로 정리해 볼게요. |
| 상황 | 독자의 처지(이직·첫 취업·현장 배치)를 그릴 수 있을 때 | 물류창고 면접에서 "지게차 면허 있으세요?"라는 질문을 받고 이 글을 찾으셨다면 잘 오셨어요. 준비 순서만 알면 생각보다 복잡하지 않아요. 지금 무엇부터 하면 되는지 바로 알려 드릴게요. |
| 통계 | 큐넷 검정현황처럼 출처 있는 수치가 있을 때 | `<연도>`년 큐넷 검정현황을 보면 지게차운전기능사 실기 합격률은 `<n>`%예요(출처: https://www.q-net.or.kr/crf005.do?id=crf00503s01&gSite=Q&gId=&jmCd=7875). 필기보다 실기에서 더 많이 떨어진다는 뜻이죠. 그래서 이 글은 실기 준비에 집중해 볼게요. |
| 오해 바로잡기 | 흔한 착각이 검색어에 묻어 있을 때 | 지게차 자격증만 따면 바로 현장에서 운전할 수 있다고 생각하기 쉬워요. 실제로는 자격 취득 뒤 면허 발급 절차가 한 단계 더 있어요. 그 차이를 순서대로 짚어 드릴게요. |

통계형은 `<n>`·`<연도>`를 `research.md`에 적은 실제 값으로만 채운다. 출처 수치가 없으면 통계형을 고르지 않는다.

## 3. 마무리 CTA 유형 3종 — 예문

⑥ 순서: 관련글 2~3개(초안에서는 `[[관련글: 주제]]` 자리) → CTA 한 단락(3~4문장). CTA 단락에는 학원명·연락처·주소(academy-profile.md 그대로)·수강생 지역 1~2개·과정 1개가 들어간다. 강점은 academy-profile.md "강점" 범위 안에서만 쓴다. 학원이 시험 장소라는 사실·암시는 어떤 유형에도 쓰지 않는다(⑧).

| 유형 | 무엇을 앞세우나 | 예문 |
|---|---|---|
| 학원 소개 | 학원의 강점 한 가지 | 클라크중장비운전학원은 경기북부 유일의 클라크 지게차 공식판매점·공식정비센터를 함께 운영해서 교육용 장비 관리가 확실해요. 의정부·양주에서 지게차운전기능사를 준비하신다면 한번 들러 보세요. 위치는 경기도 양주시 백석읍 연곡로124번길 23-36, 문의는 031-855-9948이에요. |
| 관련글 | 다음 단계 글로 이어 읽기 | 필기를 마치셨다면 위의 실기 준비 글을 이어서 읽어 보세요. 동두천·포천에서 3톤미만 지게차 과정을 찾으신다면 클라크중장비운전학원(경기도 양주시 백석읍 연곡로124번길 23-36)도 함께 알아보세요. 궁금한 점은 031-855-9948로 편하게 물어보시면 돼요. |
| 문의 | 지금 상황을 물어보라는 초대 | 내 상황에 국비과정이 맞을지 일반과정이 맞을지 헷갈리신다면 전화 한 통으로 정리해 드릴게요. 클라크중장비운전학원 031-855-9948, 주소는 경기도 양주시 백석읍 연곡로124번길 23-36이에요. 서울북부·의정부에서 다니시는 분들이 많아요. |

CTA 문장도 매번 바꾼다 — 위 예문이나 이전 글의 CTA를 그대로 쓰지 않는다(⑥ 2).

## 4. 변주 축 (design-system.md ⑦과 같은 항목)

| 축 | 선택지 | frontmatter 키 | 비고 |
|---|---|---|---|
| 도입부 유형 | 질문 / 상황 / 통계 / 오해 바로잡기 | `intro` | 위 2절 |
| 구조 템플릿 | 절차형 / 비교형 / 체크리스트형 / Q&A형 | `structure` | 위 1절 |
| 지역 키워드 조합 | 의정부·양주·동두천·포천·서울북부 중 2개 | `region` | 게이트 1에서 이랑이 고른 값 우선 |
| 마무리 CTA | 학원 소개 / 관련글 / 문의 | `cta` | 위 3절 |
| (축 아님) 글 유형 | 정보 / 홍보 | `type` | 게이트 1 선택값 그대로. ⑨ 비율용 |

규칙(⑦): `work/variation-log.md` 최근 5줄 **각각**과 비교해 4개 축(structure·intro·region·cta) 중 **2개 이상**이 달라야 한다. region은 순서를 무시하고 두 지역의 집합으로 비교한다. 로그가 없거나 비어 있으면 제약 없음. 소제목 수는 변주 축이 아니다(④ 범위 안에서 주제에 맞게).

로그 한 줄 형식(업로드 성공 시 메인이 추가): `YYYY-MM-DD | posts/NNN-slug | type | structure | intro | region | cta`
