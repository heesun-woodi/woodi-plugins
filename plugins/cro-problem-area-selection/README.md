# cro-problem-area-selection

**데이터로 실험할 문제영역을 고릅니다. 퍼널 표·Gap·Uplift를 계산하고, 두 축의 후보를 계약수 증분으로 비교해 워크숍 확정 표(P1~P7)를 만드는 클로드 스킬입니다.**

참가자는 클로드와 대화해 숫자를 찾고, 핵심 숫자만 시트에 손으로 적습니다. 붙여넣기 자동화·시트 수식 없음. 판정·합의는 사람이 합니다.

---

## 1. 설치 (2단계)

**① 마켓플레이스 추가**

```
/plugin marketplace add heesun-woodi/woodi-plugins
```

**② 플러그인 설치**

```
/plugin install cro-problem-area-selection@woodi-plugins
```

설치 확인: `/plugin` 목록에 `cro-problem-area-selection`이 보이면 완료입니다.

> 로컬 폴더로 받은 경우 ① 대신 폴더 경로를 입력하세요:
> `/plugin marketplace add /Users/본인계정/claude-cowork/woodi-plugins`

---

## 2. 시작

설치 후 새 대화창에서 아래를 입력합니다.

```
문제영역 선정 시작
```

클로드가 A축·B축 중 어느 축부터 진행할지 묻고, 4단계를 순서대로 안내합니다.

---

## 3. 4단계 흐름

| STEP | 하는 일 | 나오는 표 | 시트 착지 |
|---|---|---|---|
| **1** | 비즈니스 KPI(계약수) 합의 + 공통 퍼널 정의 | P1 KPI 합의 / P2 퍼널 표 | `1_공통_KPI_퍼널` ①② |
| **2** | 축 핵심 KPI 합의 + 축 퍼널 구체화 | P3 축 KPI 합의 / P2 축 퍼널 | `2_A축` 또는 `3_B축` ①② |
| **3** | 핵심 KPI와 상관 높은 선행지표 찾기 | P4 선행지표 | 같은 탭 ③ |
| **4** | Gap 판단 → Uplift 계산 → 확정 행 | P5 Gap / P6 Uplift / P7 확정 | 같은 탭 ④⑤ → `4_문제영역_확정` |

STEP 1은 두 페어가 함께 진행합니다. STEP 2부터 A축·B축 페어가 각자 진행합니다.

**각 표를 시트에 옮기는 방법**: 클로드가 대화에 마크다운 표로 출력합니다. 표를 보고 해당 탭의 같은 번호 섹션에 손으로 타이핑합니다. 드래그 복사는 구글시트에서 열이 나뉠 수도 있지만, 손입력이 기본입니다.

---

## 4. 진행 팁

**쿼리가 실패하거나 이벤트를 못 찾으면 즉시 손을 드세요.**
클로드가 없는 데이터를 만들어낼 수 있습니다. 15분 이상 막히면 코치를 호출합니다. 자세한 재프롬프트 패턴은 `references/funnel-verification.md`를 참고하세요.

**한 지점에서 15분 넘게 막히면 코치를 부릅니다.**
완벽한 숫자보다 출처가 명확한 숫자가 우선입니다. 이벤트를 못 찾으면 해당 칸을 비우고 `계측 공백`으로 기록하고 넘어갑니다.

**표는 손으로 시트에 옮깁니다.**
클로드가 출력한 표를 보고 시트의 같은 번호 섹션에 직접 타이핑합니다. 카드 하나가 끝날 때마다 시트에 옮깁니다. 몰아서 옮기지 않습니다.

**판정·합의는 사람이 합니다.**
P1·P3의 `합의 (O / 보류)` 열, P4의 `판정 (채택/보류)` 열, P7의 `판정` 열은 항상 공란입니다. 클로드가 채우지 않습니다. 교차 토론에서 팀이 결정합니다.

**클로드가 거절하는 것**

| 요청 | 클로드 응답 |
|---|---|
| "솔루션 아이디어 뽑아줘" | 금요일 백로그 워크숍에서 합니다 |
| "ICE 점수 계산해줘" | 금요일로 미룹니다 (ICE 합산식 `I + C + E`, 곱셈식 금지) |
| 숫자를 모를 때 대신 추정 | 칸을 비우고 `확인 필요`로 표기합니다 |

---

## 5. 이 스킬의 범위 밖

| 필요한 것 | 사용할 스킬 |
|---|---|
| 화면 스크린샷으로 사용자 문제 정의 | `cro-problem-definition` |
| 솔루션 아이디어 · ICE 점수 · 가설 백로그 | 금요일 워크숍 |

이 스킬은 **"어디에서 실험할 것인가"** 까지만 다룹니다. **"무엇이 문제인가"** 는 `cro-problem-definition`이, **"어떻게 고칠 것인가"** 는 금요일 백로그 워크숍이 담당합니다.
