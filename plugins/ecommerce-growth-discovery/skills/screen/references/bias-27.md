# BIAS 27항목 — 문구 · 판정 기준 · 가중 근거

`/ecommerce-growth-discovery:screen` STEP2에서 쓴다. 항목ID와 문구는 이 파일이 정본이다. **순서(B1→S4)를 바꾸지
않고 27개를 전부 판정한다.** 여기 실린 맥락 예시는 전부 **가상 예시**이며,
실제 우리 몰 화면을 확인한 결과가 아니다.

---

## 1. BIAS 4단계

| 단계 | 의미 | 고객에게 일어나는 일 | 판별 관찰 |
|---|---|---|---|
| **B — Block (차단)** | 뇌가 정보를 무시·차단하지 않게 | 무관하거나 복잡하면 그냥 지나친다 | 화면을 아예 보지 않는다 |
| **I — Interpret (해석)** | 정보를 쉽고 긍정적으로 해석하게 | 익숙한 방식으로만 해석한다 | 보고도 반응하지 않는다 |
| **A — Act (행동)** | 행동에 필요한 마찰 제거 | 귀찮거나 두려우면 미룬다 | 반응하지만 끝까지 안 한다 |
| **S — Store (기억)** | 경험을 긍정 감정으로 저장 | 감정으로 기억한다 | 돌아오지 않는다 |

**우선순위: Block > Interpret > Act > Store.**

---

## 2. 왜 Block부터 판정하나 (Impact 가중의 근거)

가장 흔한 오진은 **모든 문제를 Act로 진단하는 것**이다. 버튼·옵션·폼처럼 눈에 보이는
요소가 찾기 쉽기 때문이다. 그러나 Block에서 걸린 고객은 Interpret 이후 단계를 **아예
경험하지 못한다.** 상품상세 화면을 3초 만에 지나친 고객에게는 사이즈표를 아무리 잘
고쳐도 아무 일도 일어나지 않는다.

그래서 `impact-scoring.md`의 정성 심각도에 다음 가중이 붙는다.

| 실패한 단계 | 가중 |
|---|---|
| Block 실패 포함 | **+2** |
| Interpret 실패 포함 | **+1** |
| Act 실패 | 0 |
| Store 실패 | 0 |

같은 트래픽·같은 Gap이라면 Block 문제가 Act 문제보다 먼저 올라가야 한다는 뜻이다.
**Block X를 놓치면 심각도에서 +2가 통째로 빠진다.** 그래서 판정을 Block부터,
의식적으로 시작한다.

## 3. 27항목 (판정 순서 고정)

| 항목ID | 단계 | 체크 항목 |
|---|---|---|
| `B1` | Block | 1초 직관성 — 헤드라인·메인 이미지만 보고 1초 안에 무엇을 파는 화면인지 아는가 |
| `B2` | Block | 자기 관련성 — "나를 위한 이야기"로 느낄 맥락·상황 언급이 있는가 |
| `B3` | Block | 패턴 파괴 — 배너처럼 보여 무의식적으로 무시되는 영역은 없는가 |
| `B4` | Block | 선택지 과부하 방지 — 한 화면 내 주요 선택지가 5~6개 미만인가 |
| `B5` | Block | 직관 이해 — 애써 생각하지 않아도 직관적으로 이해되는가 |
| `B6` | Block | 무시 영역 회피 — 상단 배너·구석처럼 습관적으로 건너뛰는 자리에만 핵심 정보가 있지 않은가 |
| `B7` | Block | 광고 인접 회피 — 중요 정보가 **실제 광고**(외부 광고·제휴 배너) 옆에 붙어 함께 무시되지 않는가 |
| `B8` | Block | 프라이밍 — 핵심 메시지 전에 관련 정보를 미리 심어 주는가 |
| `B9` | Block | 패턴 브레이크 — 반복되는 화면 패턴을 깨어 주의를 끄는 요소가 있는가 |
| `I1` | Interpret | 익숙한 UX — 학습 없이 이해되는 보편적 패턴을 따르는가 |
| `I2` | Interpret | 혜택 우선성 — 기능 설명보다 얻는 이득이 더 크고 명확한가 |
| `I3` | Interpret | 앵커링 — 가격·가치를 판단할 비교 기준점이 있는가 |
| `I4` | Interpret | 손실 회피 — 지금 행동하지 않으면 잃는 것이 보이는가 |
| `I5` | Interpret | 인지 부하 최소화 — 짧은 문단·명확한 시각 요소로 해석에 드는 노력이 최소인가 |
| `I6` | Interpret | Labor Illusion — 기다리는 시간이 "당신을 위해 준비 중"의 가치 경험으로 바뀌는가 |
| `I7` | Interpret | 발견 용이성 — 핵심 정보·기능이 쉽게 발견되는가 |
| `A1` | Act | 마찰 제거 — 불필요한 입력·클릭이 제거되었는가 |
| `A2` | Act | 스마트 기본값 — 추천 옵션이 기본 선택되어 있는가 |
| `A3` | Act | 사회적 증거 — 다른 고객의 행동(리뷰·판매 수 등)이 확신을 주는가 |
| `A4` | Act | 희소성/긴급성 — 지금 행동해야 할 명분이 있는가 |
| `A5` | Act | 단계 쪼개기 — 복잡한 과정이 작은 단계로 나뉘어 쉬운 것부터 시작되는가 |
| `A6` | Act | 점진적 공개 — 처음엔 핵심만 보여주고 세부는 필요한 시점에 노출하는가 |
| `A7` | Act | 호기심 자극 — 정보를 일부만 보여줘 다음 행동을 부르는 장치가 있는가 |
| `S1` | Store | 즉각적 피드백 — 행동에 시각적 피드백이 즉시 제공되는가 [^s1] |
| `S2` | Store | 안심 장치 — 교환·반품·개인정보 안내 등으로 불안을 해소하는가 [^s2] |
| `S3` | Store | Delighter — 예상 밖의 긍정적인 문구·연출이 있는가 |
| `S4` | Store | 케어 신호 — 추천 이유·관리 안내 등 우리가 고객을 아낀다는 느낌을 주는가 |

[^s1]: 원 항목은 "시각/**청각** 피드백"이다. 모바일 웹 상품상세는 소리 피드백을 쓰지
않아 이 파일에서는 **시각적 피드백으로 좁혀** 적었다. 소리·진동 피드백이 있는 화면을
보게 되면 그것도 이 항목으로 판정한다.

[^s2]: 원 항목은 "**개인정보 보호**·완료 메시지"다. 이 파일에서는 이커머스 상품상세
맥락에 맞춰 **교환·반품·개인정보 안내**로 각색해 좁혔다. 결제·가입 화면을 보게 되면
개인정보 처리 고지와 완료 메시지도 이 항목으로 판정한다.

## 4. 판정 기준

| 판정 | 의미 | 성립 조건 |
|---|---|---|
| `O` | Pass | 전사한 Fact에 충족을 보여주는 근거가 있다 |
| `△` | 부분 충족 / 판단 보류 | 일부만 충족, 또는 근거가 부족해 단정할 수 없다. `❓(판독 불확실)` Fact뿐인 경우도 여기 |
| `X` | Fail | 전사한 Fact에 **명확한 미충족 근거(Fact ID)**가 있다 |

### 강제 규칙

1. **모든 `X`는 근거 Fact ID 필수.** 근거를 못 대면 `X`가 아니라 `△`다.
2. **`❓` Fact는 `X`의 근거가 될 수 없다.** 안 읽히는 글자를 "없다"로 단정하지 않는다.
3. **`X`·`△` 항목마다 고객 주어 문제 문장 초안**을 한 줄 남긴다.
   형식은 `fact-vs-problem.md`.
4. **27항목이 정본이다.** 다만 `SKILL.md`의 STEP2 축약 스위치에 따라 1차에서는
   `B1`~`B9` 9개만 판정하고, 나머지 18개는 빈 칸이 아니라 `미판정`으로 적는다.
   1차가 끝나고 확장하기로 하면 `Interpret` → `Act` → `Store` 순으로 27항목을 모두 채운다.
   `미판정`은 Fail율·심각도 계산의 분모에서 뺀다.
5. **"없음"도 근거다.** 요소가 화면에 아예 없다고 전사에 `없음`으로 기록돼 있으면
   그것은 `X`의 정당한 근거다. 반대로 "전사에 안 적혀 있다"는 근거가 아니다 — `△`다.
6. **화면 종류상 해당 없는 항목**(예: 광고 랜딩에 기다림이 없어 `I6`가 성립하지 않음)은
   `△`로 두고 근거 칸에 "이 화면에 해당 없음"이라고 적는다.

### 어느 단계인지 헷갈릴 때

| 관찰 | 단계 |
|---|---|
| 화면을 아예 보지 않는다 | Block |
| 보고도 반응하지 않는다 | Interpret |
| 반응하지만 끝까지 완료하지 않는다 | Act |
| 완료했지만 돌아오지 않는다 | Store |

## 5. 항목별 판정 가이드

> **아래 예시는 전부 가상 예시다.** 실제 우리 몰 화면을 확인한 결과가 아니므로 그대로
> 인용해 문제 문장을 만들지 않는다. 판정은 반드시 이번에 전사한 Fact로만 한다.

### Block

**B1. 1초 직관성** — 헤드라인·메인 이미지만 1초 보고 가렸을 때 무엇을 파는지 답할 수 있는가?
- `O`: 첫 화면 문구·이미지만으로 무슨 상품인지 즉시 파악된다는 근거가 있다.
- `X`: 상품명이 브랜드 코드·모델명 위주라 무엇인지 알 수 없다는 근거가 있다.
- 가상 예시(나쁨): 첫 화면 타이틀이 `BD-2401 SET`뿐이고 이불인지 커버인지 알 수 없다.
- 흔한 오판: 글자가 작아 안 읽히는 가독성 문제와 혼동한다. B1은 "인지되는가"이지
  "읽기 편한가"가 아니다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).**
  ① 첫 이미지가 분위기 컷·텍스트 배너라 품목을 알 수 없다 → `X`.
  ② 상품명이 배너·쿠폰 문구와 크기가 비슷해 어느 것이 상품명인지 구분되지 않는다 → `X`.

**B2. 자기 관련성** — "나를 위한 이야기"로 느낄 맥락 언급이 있는가?
- `X`: 모든 방문자에게 동일한 일반 문구뿐이라는 근거가 있다.
- 가상 예시(좋음): "여름 이불 정리할 때 바꾸는 계절 침구"처럼 고객 상황을 언급한다.
- 흔한 오판: 부드러운 말투를 자기 관련성으로 착각한다. 톤이 아니라 **상황·속성 언급**이
  기준이다.

**B3. 패턴 파괴** — 배너처럼 생겨서 광고로 오인돼 건너뛰는 영역은 없는가?
- `X`: 핵심 혜택 안내가 자사 프로모션 배너(쿠폰·이벤트)와 똑같은 생김새라 함께
  넘겨진다는 근거가 있다.
- **자사 프로모션 배너와 관련된 무시는 전부 여기서 본다.** 외부 광고 옆 배치는 `B7`이다.

**B4. 선택지 과부하 방지** — 한 화면 안 주요 선택지가 5~6개 미만인가?
- `X`: 한 화면에 옵션·쿠폰·이벤트·추천상품 진입점이 동시에 8개 이상 보인다.
- 흔한 오판: `I5`(인지 부하 최소화)와 섞는다. B4는 **선택지 개수**, I5는 **읽는 노력**이다.

**B5. 직관 이해** — 애써 생각하지 않아도 이해되는가?
- `X`: 옵션 이름이 내부 코드(`SS-01`, `Q-02`)라 무엇을 고르는지 설명이 필요하다.

**B6. 무시 영역 회피** — 습관적으로 건너뛰는 자리(최상단 띠·최하단)에만 핵심 정보가 있지 않은가?
- `X`: 배송 기준 금액이 최상단 롤링 띠에만 있다.

**B7. 광고 인접 회피** — 중요 정보가 **실제 광고**(외부 광고·제휴 배너) 바로 옆에 붙어
함께 무시되지 않는가?
- `X`: 사이즈 안내가 외부 제휴 광고 배너 사이에 끼어 있다.
- **자사 프로모션 배너(쿠폰·이벤트)와 생김새가 같아 함께 넘겨지는 문제는 `B3` 소관이다.**
  우리 몰에 외부 광고 지면이 없으면 `B7`은 `△` + "이 화면에 해당 없음"이다.

**B8. 프라이밍** — 핵심 메시지 전에 관련 정보를 미리 심어 주는가?
- `△`가 많이 나오는 항목이다. 근거가 없으면 무리해서 `X`로 만들지 않는다.

**B9. 패턴 브레이크** — 반복되는 이미지 흐름을 깨어 주의를 끄는 요소가 있는가?
- `X`: 상세 본문이 같은 크기 이미지의 반복이라 어디가 중요한지 구분되지 않는다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).** 상세 본문이 소제목·구분 영역
  없이 이어져 원하는 정보를 찾아 읽을 수 없다 → `X`. 캡처가 덮은 구간 안에서만 판정한다.

### Interpret

**I1. 익숙한 UX** — 학습 없이 이해되는 보편적 패턴인가?
- `X`: 옵션 선택 방식이 일반적인 형태와 달라 어떻게 고르는지 알기 어렵다는 근거가 있다.

**I2. 혜택 우선성** — 스펙 나열보다 "그래서 나에게 뭐가 좋은가"가 더 크고 앞에 있는가?
- 가상 예시(나쁨): 혼용률·원사 번수만 나열되고 "덜 덥다 / 세탁이 쉽다" 같은 이득이 없다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).** 상품명 아래 서브카피가 이득을
  말하지 않고 소재·스펙 코드·모델번호 같은 정보만 있다 → `X`.

**I3. 앵커링** — 가격을 판단할 비교 기준점이 있는가?
- `X`: 판매가 한 줄만 있고 정가·구성 대비 기준이 없다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).** 할인 상품인데 정가·할인율이
  함께 표시되지 않아 얼마를 아끼는지 알 수 없다 → `X`.

**I4. 손실 회피** — 지금 안 하면 잃는 것이 보이는가?
- 근거 없이 `X`로 몰지 않는다. 없으면 `△`.

**I5. 인지 부하 최소화** — 짧은 문단·명확한 구조로 읽는 노력이 최소인가?
- `X`: 상세 본문이 긴 이미지 한 장에 소제목 없이 이어진다.

**I6. Labor Illusion** — 기다리는 시간이 가치 경험으로 바뀌는가?
- 상품상세에는 대개 해당 없음(`△` + "이 화면에 해당 없음").

**I7. 발견 용이성** — 고객이 찾는 정보(사이즈·세탁·배송)가 쉽게 발견되는가?
- `X`: 세탁 방법이 상세 본문 맨 아래에만 있고 옵션 근처에 없다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).** 옵션 이름(SS/Q/K)만 있고
  사이즈 실측 치수(가로×세로 cm)가 옵션 근처에 없다 → `X`.

### Act

**A1. 마찰 제거** — 불필요한 입력·클릭이 제거되었는가?
- `X`: 장바구니에 담기 전에 팝업·동의를 한 번 더 거친다.

**A2. 스마트 기본값** — 추천 옵션이 기본 선택되어 있는가?
- `X`: 모든 옵션이 미선택이라 담기 버튼이 계속 비활성 상태다.

**A3. 사회적 증거** — 다른 고객의 행동이 확신을 주는가?
- `X`: 후기 수·판매 수가 화면 어디에도 없다.
- **여기서 함께 본다(체크리스트에서 중복이라 뺀 항목).** 후기 수·판매 수가 숫자로
  표시되지 않는다 → `X`. **숫자의 유무는 여기서, 그 숫자가 첫 화면에 노출되는
  위치는 체크리스트 `PP-O4`에서 본다.**

**A4. 희소성/긴급성** — 지금 행동해야 할 명분이 있는가?
- 없다고 무조건 `X`는 아니다. 근거가 있을 때만 `X`.

**A5. 단계 쪼개기** — 복잡한 결정이 작은 단계로 나뉘는가?
- `X`: 사이즈·색상·구성·추가상품을 한 화면에서 동시에 결정하게 한다.

**A6. 점진적 공개** — 처음엔 핵심만, 세부는 필요할 때 나오는가?
- `X`: 첫 화면부터 모든 스펙이 한꺼번에 펼쳐져 있다.

**A7. 호기심 자극** — 다음 행동을 부르는 장치가 있는가?
- 근거 없으면 `△`.

### Store

**S1. 즉각적 피드백** — 행동에 즉시 반응이 오는가?
- 스크린샷만으로는 대개 판정 불가(`△`). 담기 직후 화면 캡처가 있을 때만 판정한다.

**S2. 안심 장치** — 교환·반품·배송 지연 안내로 불안이 해소되는가?
- `X`: 교환·반품 조건이 결정 시점 어디에도 보이지 않는다.

**S3. Delighter** — 예상 밖의 긍정적인 문구·연출이 있는가?
- 없어도 `X`가 아니라 `△`인 경우가 많다.

**S4. 케어 신호** — 추천 이유·관리 안내 등 우리가 고객을 아낀다는 느낌이 있는가?
- 가상 예시(좋음): "첫 세탁 전 이렇게 해 주세요" 같은 사용 안내가 결정 전에 보인다.
