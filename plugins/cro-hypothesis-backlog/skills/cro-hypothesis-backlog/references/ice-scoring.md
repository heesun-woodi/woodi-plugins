## 공식 (정본 — 위반 금지)

```
ICE = Impact + Confidence + Ease     (각 1~10점, 합산, 총점 최대 30점)

QuickWin = ICE ≥ 21   또는   (ICE ≥ 15 AND Ease ≥ 8)
```

**곱셈식·평균식은 어떤 형태로도 출력하지 않습니다.** 과거 문서에 다른 표기가
있으면 I/C/E 원 점수만 살려 합산으로 재계산합니다.

**QuickWin 두 갈래의 의미**

- `ICE ≥ 21` — 세 축이 고르게 높은 정공법 가설. 다음 스프린트에 우선 배정합니다.
- `ICE ≥ 15 AND Ease ≥ 8` — 총점은 중간이지만 당일·이틀 내 붙였다 뗄 수 있는
  가설. 실패해도 리스크가 낮고 학습이 빠릅니다. 스프린트 공백을 막는 QuickWin입니다.

## 앵커링 방지 게이트

**스킬은 참가자의 개인 스코어링이 끝났다는 확인을 받은 뒤에만 H4를 출력합니다.**

H4 표 상단에 다음 고정 문구를 반드시 출력합니다 (계약 §3 H4 원문):

> ⚠️ 그루밍 전 1차(잠정) 점수이며, 스킬 점수는 보조 참고용입니다. 팀 점수는
> 개인 스코어링 → 분산 확인 → 조정 토론으로 확정합니다.

`04c` 카드 4 원문: "클로드 점수가 팀 점수가 되면 안 된다." 스킬 점수를 팀 점수로
채택하면 앵커링 방지 장치가 무력화됩니다.

## I — Impact 이관 규칙

**I = 입력 리스트의 Impact 점수 이관. 재계산 금지.**

`문제 Impact 점수 = (트래픽 영향 + 벤치마크 Gap + 정성 심각도) / 3` 은
문제정의 단계(`pd-output-contract.md` §6)의 공식입니다. 이 세션은 그 결과값을
근거로 옮겨 적는 것이며, 스킬이 새로 계산하지 않습니다.

**I 앵커 참고 (이관 전 맥락 확인용 — 실제 값은 항상 이관):**
지표 20%↑ 개선·트래픽 대 → 10 / 10% 개선·트래픽 중 → 5 / 5% 미만·트래픽 하 → 1

### 가중 반영 여부 확인 (`04c` 카드 4 방식)

H4 출력 전 다음을 확인합니다:

> "03a에서 정성 심각도에 BIAS 가중(Block +2 / Interpret +1)을 이미 반영했는가: 예 / 아니오"

- **예** → I에서 아무것도 더하지 않습니다. 이관값 그대로. **중복 가산 금지.**
- **아니오 또는 불명확** → 아래 폴백 재계산 경로를 씁니다.

### 폴백 재계산 경로 (가중 미반영·불명확 시)

**Impact 총점에 직접 +2를 얹지 않습니다.** 반드시 심각도 경로를 씁니다:

```
심각도(가중) = MIN(10, 심각도 원점수 + (Block 실패면 +2) + (Interpret 실패면 +1))
Impact 재계산 = (트래픽 영향 + 벤치마크 Gap + 심각도(가중)) / 3
```

재계산했다는 사실과 계산 과정 한 줄을 I 근거 칸에 명시합니다.

> **+0.67 산술 이유 (`04a` 4-4절 원문):** 심각도에 +2를 더한 뒤 /3으로 나누면
> Impact 증분은 +0.67입니다. Impact 총점에 직접 +2를 얹으면 +2가 됩니다. 경로가
> 섞이면 같은 문제가 채점자에 따라 1점 이상 벌어집니다. **폴백에서도 반드시
> 심각도 경로(÷3)를 씁니다. 총점 직접 가산은 경로 불일치입니다.**

## C — Confidence 앵커 기준표 (해빗팩토리 적용판)

H2 근거 표의 "C 앵커 밴드(제안)" 열과 연결해 아래 4밴드를 적용합니다.

| 점수 | 기준 |
|:-:|---|
| 10 | 검증된 자사 데이터 + 경쟁사 대부분 채택 + 성공 경험 |
| 7~9 | 경쟁사 벤치마크 강함, 신뢰할 만한 레퍼런스 다수 (데스크리서치 3곳 이상) |
| 4~6 | 경쟁사 1~2곳 채택, 또는 케이스 스터디·행동경제학 이론 수준 |
| 1~3 | 근거 부족, 직관 수준 — **합성 인터뷰만 있는 문제는 반드시 여기** |

**합성 근거 상한 (하드 제약):** 근거 유형이 합성 인터뷰뿐이면 C는 1~3점을 넘지
않습니다 (계약 §7 / `03b` §0). H2에 "확인되지 않음"이 남아 있는 근거는 1~3점으로
처리합니다.

코치 개입: 합성 근거 C를 7점으로 매기면 즉시 `03b` §0을 상기시키고 1~3점으로
교정합니다.

## E — Ease 규칙

**스킬은 Ease를 추정하지 않습니다.** 참가자(담당자)에게 직접 묻습니다.

질문 프레임 — 개발 공수만이 아니라 **인프라·내부 승인·법무 검토를 포함한 종합
코스트**를 워킹데이 기준으로 답해달라고 안내합니다. 개발이 30분이어도 법무 검토가
2주면 Ease는 낮습니다.

| 점수 | 기준 (워킹데이) |
|:-:|---|
| 10 | 당일 구현, 담당자 단독 |
| 7~9 | 2~3일 이내 |
| 4~6 | 5일 이내 (1주일) |
| 1~3 | 10일 이상 (2주일 이상) |

`E 근거` 칸 첫머리에 **`(잠정)`을 강제합니다.** Sprint 1 스프린트 플래닝에서
지원 부서(개발·디자인)가 재조정합니다.

## 점수 몰림 처리

점수가 전부 8~9점으로 몰리면 감으로 채점된 신호입니다.

→ **근거 칸을 먼저 채우게 하고 점수는 그다음에 확정합니다.** ICE는 절대 평가가
아니라 같은 화면 안 문제들 사이의 상대 평가입니다. 근거 없는 점수는 무효입니다.

코치 개입 기준 (`04a` 5절):
- 전부 8~9 몰림 → 근거 칸 먼저, 점수는 그다음
- 합성 근거 C 7점 → 1~3 교정

## H4 사람 절차 안내 (스킬은 리마인드만)

사람이 실행하는 절차입니다. 스킬은 아래 순서를 안내합니다.

| 시간 | 하는 일 | 주의 |
|---|---|---|
| 15분 | **개인 스코어링** — 각자 I/C/E + 근거 한 줄 기입 | 남의 점수를 보기 전에 매깁니다. 대화 금지. |
| 5분 | **분산 확인** — 크게 갈린 항목 표시 | 모두 같은 점수면 논의하지 않습니다. |
| 15분 | **조정 토론** — 갈린 항목만. 최고점·최저점 근거 발표 | **평균 내기 금지.** |
| 5분 | **잠정 확정** — 합산, QuickWin 판정, "그루밍 전 1차(잠정)" 라벨 | 수렴 안 한 항목은 그대로 기록. |

**왜 평균을 내지 않는가 (`04a` 4-4절 원문):** 점수가 갈렸다는 것은 서로 다른
정보를 갖고 있다는 뜻입니다. 평균을 내면 그 정보가 버려집니다. 수렴하지 않으면
그루밍 과제로 넘깁니다.

**분산 기록란은 사람이 채웁니다.** 스킬은 형식을 보여주고 기록을 안내합니다.

| 가설 # | 갈린 축 | 최고점·근거 | 최저점·근거 | 잠정 처리 | 그루밍 과제 |
|---|:-:|---|---|---|---|
| | I / C / E | | | | |

이 표가 Sprint 1 그루밍의 착수 목록이 됩니다. 비워두고 끝내지 않습니다.

## 금지 사항 요약

- 곱셈식·평균식은 수식 형태로 표기 금지 (예시 형태 포함, 형태 불문)
- 스킬이 E를 추정해 H4에 대입하는 행위

- Impact 총점에 직접 BIAS 가중치를 가산하는 행위 (심각도 경로만 허용)
- 원천 문서에 없는 앵커 기준을 새로 발명하는 행위
- 개인 스코어링 완료 확인 전 H4 출력
