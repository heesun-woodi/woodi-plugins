## 1. 정성 근거를 받았을 때 처리 원칙

- **원문 인용을 그대로 보존**하고 출처를 함께 표기한다. 요약하되, 원문에 없는 감정·수치를
  덧붙이지 않는다. 예: 인터뷰 원문이 "부담스럽다"면 문제 문장에서 "매우 불쾌하다"처럼 강도를
  올려 쓰지 않는다.
- 출처 표기는 최소 **누가/무엇/언제**를 남긴다 — 예: "홍보라, 진단 인터뷰(구술값), 2026.08.05".
- 정성 근거는 **왜 그게 문제인가**를 보강하는 층이다. 화면 Fact를 대체하지 않는다.

## 2. 화면 Fact와의 관계 — 정성 근거만으로 확정하지 않는다

정성 근거(VOC·인터뷰)만으로는 T2(BIAS)의 `X`나 T3(CRO 체크리스트)의 `Fail`을 확정하지 않는다.

| 상황 | T2/T3 판정 |
|---|---|
| 화면 전사(T1 Fact ID)에 명확한 미충족 근거가 있다 | `X` / `Fail` |
| 정성 근거만 있고 화면 전사 근거가 없다 | `△` 또는 `N/A` |
| 화면 전사 근거 + 정성 근거가 같은 지점을 가리킨다 | `X` / `Fail` (근거유형 `관측+정성`) |

정성은 "이 화면 요소가 왜 이탈을 만드는가"를 설명하는 데는 강하지만, "이 요소가 화면에
있는지/없는지"를 증명하지는 못한다. 그 증명은 T1 워크스루가 한다.

## 3. 근거유형 표기 규칙 (계약 T4 5열)

T4 문제정의 리스트의 **근거유형** 칸은 아래 셋 중 하나로만 쓴다.

| 값 | 조건 |
|---|---|
| `관측` | 화면 전사(T1)·정량 데이터·BIAS·체크리스트 진단 등 관측 근거만 있다 |
| `정성(VOC·인터뷰)` | VOC·리뷰·CS 문의·인터뷰 등 정성 근거만 있다 |
| `관측+정성` | 관측 근거와 정성 근거가 **같은 지점**을 가리킨다 |

`관측+정성`이 가장 신뢰도가 높다 — 두 층이 독립적으로 같은 결론을 가리키면 문제가 확정된다.
하나만 있을 때보다 솔루션 단계에서 뒤집힐 위험이 훨씬 낮다.

## 4. 소표본·시점차 주의 (03c 사용법 3줄 원칙)

정성 근거를 인용할 때 아래 세 원칙을 따른다(`03c_qual-input-cards.md` 그대로).

1. **모집단이 다른 조사는 합산·직접 비교하지 않는다.** 서로 다른 조사(예: 정량 U&A 조사와
   별도 설문)의 수치를 더하거나 나란히 비교하지 않는다.
2. **삼각검증은 독립적으로 같은 결론이 나올 때만** "확인됨"으로 취급한다. 서로 다른 소스가
   같은 지점을 가리킬 때만 신뢰도를 올려 말한다 — 한 소스의 반복 언급을 삼각검증으로 착각하지
   않는다.
3. **구술값은 실측치와 다를 수 있다.** 인터뷰에서 나온 수치(전환율·이탈률 추정 등)는 코칭
   대상자의 기억에 의존한 값이다. 실측 자료가 확보되면 그 값으로 교체한다.

소표본 문항(응답자 수가 적은 항목)은 방향성 참고용으로만 쓰고, 그 수치만으로 단독 의사결정하지
않는다.

## 5. 합성 인터뷰는 이번 세션 범위 밖

`가설(합성)` 근거유형 — 합성 인터뷰 기반 근거 — 는 **Sprint 1~2**에 이연된 기능이다. 이번
문제정의 라이브 세션에서는 쓰지 않는다. 참가자가 합성 인터뷰를 요청하면 이연 범위임을 안내하고
정성 근거는 실제 VOC·진단 인터뷰로 한정한다.
