# cro-problem-definition

**앱 화면 스크린샷 3장으로 사용자 문제를 정의하고, 구글시트에 바로 붙일 표를 만드는 클로드 스킬입니다.**

시그널플래너는 모바일 앱이라 클로드가 화면을 직접 볼 수 없습니다. 그래서 **여러분이 올린
스크린샷이 유일한 근거**입니다. 이 스킬은 그 스크린샷을 먼저 글로 옮겨 적고(전사), 여러분에게
"맞는지" 확인받은 다음에야 진단을 시작합니다. 클로드가 화면을 상상해서 지어내는 것을 막기
위한 장치입니다.

개발 지식은 전혀 필요 없습니다. 클로드가 **한 번에 하나씩** 물어보고, 여러분은 답만 하시면
됩니다.

---

## 1. 설치 (3단계)

클로드 세션에 아래를 **한 줄씩 순서대로** 입력하세요.

**① 마켓플레이스 추가**

```
/plugin marketplace add heesun-woodi/woodi-plugins
```

**② 플러그인 설치**

```
/plugin install cro-problem-definition@woodi-plugins
```

**③ 확인**

```
/plugin
```

목록에 `cro-problem-definition`이 보이면 끝입니다.

> 로컬 폴더로 받으신 경우에는 ① 대신 폴더 경로를 넣으세요:
> `/plugin marketplace add /Users/본인계정/claude-cowork/woodi-plugins`

> 자동완성으로 확인할 경우 네임스페이스 형태(`/cro-problem-definition:...`)로 뜰 수
> 있습니다. 이 형태로 떠도 설치된 것이니 "안 뜬다 = 미설치"로 오판하지 마세요 — `/plugin`
> 목록에서 확인하는 것이 정확합니다.

### ⚠️ 이미 설치하신 분은 업데이트가 필요합니다

이 스킬은 **구버전(v1)에서 결과물 형식이 완전히 바뀌었습니다.** 구버전은 시트에 붙여넣는
TSV와 셀 주소(A11, A34…)를 알려주는데, 지금 시트에는 그 셀이 없습니다. 아래로 최신 버전을
받으세요.

```
/plugin marketplace update woodi-plugins
```

그다음 `/plugin` 목록에서 `cro-problem-definition`을 다시 설치(또는 업데이트)하고
클로드를 새로 시작하세요. **판별법**: 스킬이 "A89 셀에 붙이세요" 같은 셀 주소를 말하면
구버전입니다. 최신 버전은 "이 표를 복사해 **문제정의 리스트 섹션**에 붙여 넣으세요"라고만
말합니다.

## 2. 첫 실행

설치가 끝나면 새 대화창을 열고 이렇게만 입력하세요.

```
문제정의 시작
```

그러면 클로드가 순서대로 물어봅니다.

| 순서 | 클로드가 묻는 것 | 여러분이 준비할 것 |
|---|---|---|
| 1 | **어느 축인가요?** | A축(상담방 오픈 **전**) / B축(상담방 오픈 **후**) 중 하나 |
| 2 | **화면 정보 카드** | 화면명 / 진입 경로 / 문제영역 / 유입 맥락 / 기기·OS (5칸) |
| 3 | **스크린샷 3장** | ① 진입 직후 ② 중간 ③ 전환 직전 (길면 최대 6장) |
| 4 | **정성 근거 있나요?** | VOC·인터뷰 인용·`03c` 정성 인풋 카드 — 없으면 "없음" |
| 5 | **"전사 확인"** | 클로드가 옮겨 적은 화면 내용을 실제 화면과 대조 |

### ⚠️ 스크린샷 올리기 전 — 마스킹 필수

실제 고객의 **이름 · 전화번호 · 증권번호 · 계약번호 · 생년월일 · 주소**가 화면에 보이면
**반드시 가리고** 올려주세요. 클로드는 이런 정보가 보이면 진행을 멈추고 다시 올려달라고
요청합니다.

### 파일명 권장 형식

```
A_01_보험분석결과_1진입.png
축_연번_화면명_순서라벨
```

다른 이름이어도 진행은 됩니다. 클로드가 그 이름 그대로 씁니다.

### "전사 확인"이 뭔가요

클로드가 스크린샷을 읽어서 "1. 헤드라인 — 내 보험 점검 결과 / 2. 하단 버튼 — 점검신청하기…"
처럼 번호를 매겨 적어줍니다. 그걸 실제 화면과 대조해 주세요.

- 틀린 게 있으면 → `3번 수정: 실제 문구는 ○○` 형식으로 알려주세요
- 다 맞으면 → **`전사 확인`** 이라고 입력하세요

**이 입력을 하기 전에는 진단이 시작되지 않습니다.** 답답해 보여도 이게 핵심입니다 — 여기서
틀린 채로 넘어가면 뒤의 모든 진단이 틀립니다.

`❓` 표시는 클로드가 "글자가 작아서 못 읽었다"는 뜻입니다. 그 부분은 여러분이 실제 문구를
알려주시면 됩니다.

## 3. 무엇이 나오나요 — 5단계 산출물

| 단계 | 하는 일 | 나오는 것 |
|---|---|---|
| STEP 0 | 인테이크 | 축 확정 + 화면 정보 + 스크린샷 + 정성 근거 |
| STEP 1 | 화면 전사 → **확인 게이트** | **T1 워크스루 Fact 로그 (6열)** — 관측 사실 로그 |
| STEP 2 | BIAS 15항목 진단 | **T2 BIAS 15항목 판정 (6열, 15줄)** — O/△/X |
| STEP 3 | CRO 체크리스트 진단 | **T3 CRO 체크리스트 판정 (5열)** — Pass/Fail/N/A + 지배 병목 |
| STEP 4 | 고객 주어 문제 문장 만들기 | 문제 후보 5~10개 (PR-01~) |
| STEP 5 | Impact 점수 | 계산 과정 표 + **T4 문제정의 리스트 (12열)** |

클로드가 표를 **대화 안에 그려서** 줍니다. 그 표를 드래그해 복사한 다음, 구글시트의
해당 탭·섹션에 붙여 넣으시면 칸이 그대로 갈라집니다. 어느 섹션에 붙이는지는 클로드가
표마다 한 줄로 알려줍니다.

| 표 | 붙일 시트 섹션 | 이식 |
|---|---|---|
| T1 | 워크스루 Fact 로그 | 선택 (근거 추적이 필요할 때만) |
| T2 | BIAS 15항목 판정 | 필수 — **아래 주의** |
| T3 | CRO 체크리스트 판정 | 필수 (생략했으면 공란) |
| T4 | 문제정의 리스트 | **필수 — 최종 산출물** |

> ⚠️ **T2만 예외입니다.** 시트의 BIAS 섹션에는 `체크 항목` 열이 하나 더 있어 **7열**인데
> 클로드가 주는 표는 6열입니다. 그대로 붙이면 15줄이 한 칸씩 밀립니다. **항목ID(B1, B2…)를
> 맞춰서 `판정` 열부터** 옮겨 적으세요. 체크 항목 문구는 시트에 이미 적혀 있으니 그대로 둡니다.

### 표를 붙였는데 한 칸에 다 들어갔어요

렌더된 표를 **드래그해서** 복사하셨는지 확인해 주세요. 그래도 한 칸으로 붙으면 열별로
나눠 옮기시면 됩니다. 오래 붙잡지 마시고 코치를 부르세요.

### Impact 점수는 누가 계산하나요

**클로드가 직접 계산합니다.** 심각도 원점수를 제안하고, BIAS 가중치(Block +2 / Interpret +1,
최대 10점)를 적용한 다음 `(트래픽 + Gap + 가중 심각도) / 3`을 소수 1자리로 냅니다.
계산 과정을 표로 보여주니, **다르게 보이는 점수나 근거가 있으면 그 자리에서 말씀해 주세요.**
클로드가 반영해 다시 계산하고 T4를 새로 줍니다.

트래픽·Gap 두 값만은 여러분이 알려주셔야 합니다. 클로드는 이 두 값을 지어내지 않습니다.

## 4. 알아두실 것

### 시간이 부족하면 (B축만 해당)

STEP 3(CRO 체크리스트)은 18항목이라 20분 넘게 걸립니다. 클로드가 시작 전에
**"생략하고 STEP 4로 갈까요?"**라고 물어봅니다. 생략해도 BIAS 진단만으로 문제 정의는
완성됩니다. 부담 없이 생략하세요.

### 클로드가 거절하는 것

| 요청 | 클로드 응답 |
|---|---|
| "그래서 어떻게 고쳐요?" / "개선안 뽑아줘" | **8/14(금) 백로그 워크숍에서 합니다** |
| "ICE 점수도 매겨줘" | 같은 이유로 금요일로 미룹니다 |
| 숫자를 모를 때 대신 추정해 달라 | 칸을 비우고 `코치 확인 필요`로 표기합니다 |

오늘 목표는 **"무엇이 문제인가"까지 확정**하는 것입니다. 지금 솔루션으로 넘어가면 문제 정의가
솔루션에 맞춰 휘어집니다. 떠오른 아이디어는 메모만 해두셨다가 금요일에 가져가세요.

### 숫자 두 개는 미리 찾아두세요

STEP 5에서 클로드가 물어봅니다. 오전 워크숍 시트에서 미리 확인해 두시면 빠릅니다.

- **트래픽 값** — 이 화면 구간을 지나는 사용자 수 또는 비중 (오전 워크숍 시트의 해당 축 탭)
- **벤치마크 Gap 배수** — %p가 아니라 "몇 배 낮은가" (같은 탭)

없으면 그냥 "모르겠다"고 하셔도 됩니다. 클로드가 지어내지 않고 빈칸으로 둡니다.

## 5. 폴백 — 잘 안 될 때

| 증상 | 대응 |
|---|---|
| `/plugin install`이 안 먹는다 | 클로드 재시작 후 `/plugin` 으로 마켓플레이스가 등록됐는지 확인 |
| 스킬이 안 뜬다 | "문제정의 시작" 대신 **"cro-problem-definition 스킬로 화면 진단해줘"**라고 명시 |
| 그래도 안 뜬다 | 채팅에 이렇게 붙여넣으세요: **"이 대화에서 `cro-problem-definition` SKILL.md 절차를 그대로 따라줘. STEP 0부터."** 그다음 코치에게 SKILL.md 내용을 요청하세요 |
| 그래도 막히면 | 코치가 안내하는 `03a` §9 프롬프트 카드(카드 0 전사 → 0-1 BIAS → 1~3)와 03d 발췌본으로도 같은 산출물을 만들 수 있습니다 |
| 클로드가 화면을 지어낸 것 같다 | **"확정 전사에 없는 내용입니다. 근거 Fact ID를 붙여 다시 판정해 주세요"** 라고 말하세요 |
| 클로드가 여러 질문을 한꺼번에 쏟는다 | **"한 번에 하나씩 물어봐 주세요"** |
| 전사 확인 없이 진단을 시작했다 | **"전사 확인 아직 안 했습니다. STEP 1로 돌아가 주세요"** |
| 표가 한 칸으로 붙는다 | 렌더된 표를 드래그해 복사했는지 확인 → 그래도 안 되면 열별로 나눠 옮기기 |
| 대화가 너무 길어져 느려졌다 | 새 창을 열고 확정된 T1·T2 표(T3까지 진행했다면 T3도)를 붙여넣은 뒤 **"다음 STEP부터 이어서"** |

## 6. 마지막 — 완료 판정 7체크

세션 끝에 클로드가 아래 7개를 함께 점검합니다. 시트 `완료 판정 체크` 섹션에 Y/N을 기록하세요.

1. 스크린샷 전사가 "전사 확인"으로 승인되었는가
2. BIAS 15항목 전부 판정되었는가
3. X·△ 항목마다 문제 문장 초안이 있는가
4. 문제 문장에서 솔루션이 자동으로 따라 나오지 않는가
5. 문제 문장이 전부 **고객 주어** 형식인가 ("고객은 이 ○○에서 ~")
6. 모든 점수(트래픽·Gap·심각도)에 근거 한 줄이 붙어 있는가
7. T4 문제정의 리스트가 시트에 옮겨졌는가

하나라도 N이면 그 단계로 돌아가면 됩니다.
