### 2. 채택 조건

> **안내**: **`n/N` 단위**로 씁니다(백분율 금지). **어느 축**(멈춤 / 믿음 / 실행의향)의 무엇인지를
> 문장 안에 넣고, **양쪽 조건**으로 씁니다 — 어느 안에서 무엇이 나오고 **동시에** 다른 안에서
> 무엇이 나와야 하는지. (❌ "반응이 좋으면 채택" — 측정 불가입니다)
> **그리고 판정형 동사로 끝맺지 마세요** — `채택`·`기각`·`순위`·`탈락`·`추천`·`권장`.
> ❌ `…이면 ㉯를 채택한다` → ✅ `…이면 ㉯ 방향이 지지된다`. 이 문장은 나중에 그대로 인용되고,
> 판정형 어휘가 인용되면 집계가 멈춥니다. **뜻은 같으니 표현만 중립으로** 씁니다.

```
답:
```

### 3. 기각 조건

> **안내**: **기각 조건이 없는 사전등록은 사전등록이 아닙니다.** 「**문구가 레버가 아니다**」가
> 나올 자리를 만드세요 — 예: *「반응 차이가 없거나 두 안 모두 같은 장벽에서 막히면 다른 레버를
> 본다」*. 결과가 어느 쪽으로 나와도 정보가 되게 설계합니다.
> **2번과 같이 판정형 동사로 끝맺지 않습니다** — `…것으로 판정` / `…지지되지 않는다`로 씁니다.

## 저장 · 잠금

```bash
# 1) 위 Part B 표만 남겨 파일로 저장한다
#    <run>/prereg.md

# 2) GATE 1 통과 시점에 해시를 기록한다 (제시물 명세와 함께)
shasum -a 256 <run>/prereg.md <run>/stimuli.md
#    → manifest.json 의 prereg_sha256 · stimuli_sha256

# 3) 그 뒤 다시 계산하지 않는다 — 리뷰어가 재계산해 대조한다
```

**해시가 없으면 「사전등록했다」고 말할 수 없습니다.** 해시 없는 run은 신뢰등급 C 상한입니다.

## 넘어가기 전 7가지 확인

- [ ] 1행이 **행동**이고, 두 선택지가 명시돼 있다
- [ ] 2행이 **`n/N`**이고, **어느 축**의 무엇인지가 문장 안에 있다
- [ ] 3행이 **비어 있지 않고**, 「문구가 레버가 아니다」가 나올 자리가 있다
- [ ] 4행의 **N이 숫자**이고, 백분율 단독 표기가 없다
- [ ] 5행이 **시드 값** 또는 `해당 없음 — 인구통계 호출 경로`로 채워졌다
- [ ] 2·3행이 **판정형 동사**(`채택`·`기각`·`순위`·`탈락`·`추천`·`권장`)로 **끝맺지 않는다**
- [ ] **7행(대조군 안)** 과 **8행(실무자 검토 — 이름·역할·날짜)** 이 **Part B 표에 남아 있다**
