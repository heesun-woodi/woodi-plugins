# 1차 가공 — transcript 교정 프롬프트

`transcript_build.py chunks` 로 만든 청크마다 이 프롬프트를 적용한다.
목적은 **읽을 수 있게 만드는 것**이지 요약이 아니다. 요약은 2차 가공에서 한다.

## 프롬프트

```
아래는 회의 녹음을 STT로 전사한 원문 조각이다. 다음 규칙에 따라 교정하라.

[해야 할 것]
- STT 오인식으로 깨진 단어를 문맥에 맞게 교정한다
- 아래 용어집에 있는 고유명사는 표기를 통일한다
- 필러("어", "음", "그", "저기")와 무의미한 반복을 제거한다
- 문장부호와 띄어쓰기를 정리한다
- 같은 화자의 끊긴 문장을 자연스럽게 잇는다

[하지 말아야 할 것]
- 내용을 요약하거나 압축하지 않는다. 발화는 모두 남긴다
- 없는 내용을 추론해 채워 넣지 않는다
- 발화 순서를 바꾸지 않는다
- 화자 라벨(화자1, 화자2)을 바꾸지 않는다 — 화자 이름은 다음 단계에서 처리한다
- 알아들을 수 없는 구간은 임의로 채우지 말고 [불명확] 으로 표기한다
- ⚠️저신뢰 로 표시된 구간은 특히 보수적으로 다룬다. 확신이 없으면 원문을 유지한다

[출력 형식]
입력과 동일한 `[타임스탬프] 화자N: 내용` 형식. 설명이나 머리말 없이 교정된 본문만 출력한다.

[용어집]
{glossary}

[원문]
{chunk}
```

## 운영 메모

- 청크는 반드시 화자 턴 경계에서 잘라야 한다(스크립트가 처리). 문장 중간에서 자르면 교정 품질이 급격히 떨어진다.
- 오버랩 구간은 두 청크 모두에서 교정되므로, 이어붙일 때 **뒤 청크의 오버랩 부분을 버린다**.
- 2~3시간 회의는 청크가 20개를 넘을 수 있다. 병렬 처리하되 순서를 유지해 이어붙인다.
