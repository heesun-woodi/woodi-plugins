## 2. 출처 3단계 표기 (hb §7-5 정본)

| 상태 | 표기 | C 밴드 반영 |
|---|---|---|
| 페이지를 실제로 열어 확인 | `URL + 확인일` | 정상 반영 |
| 검색 결과 요약에만 등장, 원문 미확인 | `2차 인용 — 원문 미확인` | 반영하되 **밴드 하단** |
| 찾지 못함 | `확인되지 않음` | 미반영 |

**존재하지 않는 URL·수치·사례를 만들지 않는다.** 그럴듯한 링크·통계를 생성하는 것은 계약 §7-9 하드 금지다. 못 찾았으면 `확인되지 않음`으로 적는 것이 정답이다.

## 3. C 밴드 기여 규칙 (G5 4열)

C 재산정의 정본은 **hb §7-4(4밴드) + §7-4a(Target 타당성)**다 — 이 계약은 재정의하지 않는다 (계약 §7-4). G5의 `C 밴드 기여` 열은 `1~3` / `4~6` / `7~9` / `10` 중 하나를 **제안**한다 — 확정은 사람.

- **합성-only 상한 1~3 하드**: 근거가 유형 6(합성소비자 UT)뿐이면 어떤 경우에도 1~3을 넘지 않는다.
- **BIAS 원리 명시 가능이면 4~6 밴드 하단**: 유형 7로 적용 전술의 행동경제학 원리를 댈 수 있으면, 외부 사례가 없어도 1~3으로 내리지 않는다. 1~3은 합성-only·직관·원리조차 제시 못 하는 경우다.
- 출처 상태가 `2차 인용`이면 해당 근거의 기여는 밴드 하단, `확인되지 않음`이면 미반영.
- 스킬 제안은 보조 참고값이다 — G6 상단 고정 문구와 앵커링 방지 게이트(계약 §7-2)가 그대로 적용된다.

## 4. Counter Rationale + Guardrail 후보 (G5 하단 필수)

G5 표 아래 별도 행으로 출력한다 — 완료 판정(계약 §9-5)의 필수 요소다.

| 항목 | 형식 |
|---|---|
| **Counter Rationale** | 실패 시나리오 한 줄 + 그때 무너질 지표 1개 (예: "CTA가 본래 목적을 방해하면 → 진행 현황 카드 클릭률 하락") |
| **Guardrail 후보** | 무너질 지표를 Guardrail 후보로 지목 + **`확정은 실험설계 소관`** 표기 |

- Guardrail이 그 가설의 R과 같으면 한 단계 뒤 지표로 민다 (hb §7-6: R이 진입률이면 Guardrail은 완료율).
- 측정 불가 노드를 지목할 때는 `세팅 의존성` 병기.
- Secondary·Guardrail의 **확정**은 이 스킬의 범위 밖이다 (계약 §7-9) — 후보 지목까지만 한다.

## 5. Target 3법 (계약 §7-7 정본)

| 방법 | 언제 | 비고 |
|---|---|---|
| 벤치마크 | 신규 지면·자사 데이터 없음 | 산업평균·경쟁사·과거의 우리. 보수성 근거 병기 권장(예: "중앙값의 60%") |
| MDE 근사 | 기존 지면 개선 | **근사까지만** — 정밀 샘플사이즈는 실험설계 소관, `실험설계에서 재확정` 표기 강제 |
| 내부 Gap | 유사 영역·상위 코호트 실측 | 정확도·설득력 낮음 표기 |

- **방법 미병기 Target은 완성으로 치지 않는다.** G4 `설정 방법` 행에 3법 중 택1을 반드시 쓴다.
- **MDE는 근사까지만.** 트래픽 기반으로 검출 가능한 최소 효과의 자릿수를 잡는 것까지 — 정밀 샘플사이즈·기간 계산은 하지 않고(계약 §7-9 하드), `실험설계에서 재확정`을 반드시 표기한다.
- **Uplift 기대개선율(낙관)과 Target은 일치해야 한다** — 다르면 정합 질문을 던진다.

## 6. Target 타당성 → C 반영 (hb §7-4a 정본 — 매핑 M3)

C는 "이 솔루션이 통할 것 같은가"만이 아니라 **"이 Target이 말이 되는 수치인가"**까지 담는다. 근거가 같아도 Target이 다르면 C가 달라진다.

| Target의 성격 | C 반영 |
|---|---|
| 벤치마크·자사 실측·MDE 등 **산출 근거가 붙은 수치** | 밴드 내 **상향** |
| 근거 없이 관행으로 잡은 수치 (예: 이유 없는 "10%") | 밴드 내 **하향** |
| 근거 대비 **과한 수치** (예: 이론 근거만 있는데 상대 +50%) | 밴드 자체를 **한 단계 내림** |
| **Target 미기재** | **C 공란 + `Target 미기재 — 타당성 판단 불가`** |

- 이 규칙은 밴드를 새로 만들지 않는다 — hb §7-4의 4밴드 안에서 위치를 조정한다.
- Target 산출 근거는 `C 근거` 한 줄에 함께 적는다. G4 `타당성 자기평가` 행이 이 4분기 중 어디인지를 기록한다.

## 7. Target 정당화 어법 — 모범 문형

Target은 숫자만 던지지 않고 **보수성의 근거**를 한 줄로 병기한다. exp-014 사례의 어법:

> **"업계 중앙값의 60% 수준 = 보수적 목표"** — 벤치마크 전체가 아니라 그 일부만 회수하겠다는 산출 논리가 한 줄에 담겨 있다.

같은 문형의 변주:

- 벤치마크법: "벤치마크 {X}% 대비 Gap의 절반 회수 = {Target}%"
- 내부 Gap법: "상위 코호트 실측 {X}% 수준까지 — 동일 사용자군이 이미 내는 값이므로 도달 가능"
- MDE 근사법: "트래픽 기준 검출 가능한 최소 효과 근사 {X}% — 실험설계에서 재확정"

과한 목표는 개선이 있었는데도 실패로 판정되게 만든다. 보수성 근거가 붙은 Target이 hb §7-4a의 "밴드 내 상향" 재료가 된다.
