# cro-hypothesis-grooming

백로그에 등록된 가설의 **근거를 채워 ICE 점수를 올리는** 가설 그루밍 플러그인입니다. 해빗팩토리 CRO 코칭 Sprint 1의 그루밍 세션과 개인 과제에서 사용합니다.

> **그루밍이란** — "가설의 근거를 탄탄하게 하여 ICE 점수를 높여서 스프린트 열차에 탈 우선순위라는 것을 주장하기 위해" 하는 작업입니다. 가설 문장을 바꾸지 않습니다. 근거가 바뀌면 점수가 바뀝니다.

## 무엇을 하나요

**수행 모드** (참가자용) — 가설 1건씩:

1. **DEC-005 이관** — 구 규칙으로 쓴 가설의 솔루션 형태를 Variant 후보로 분리하고 문장을 정리합니다 (의미는 바꾸지 않습니다)
2. **Problem Validation** — 진짜 문제고 비싼 문제라는 근거를 5차원(트래픽·퍼널 병목·벤치마크 Gap·정성 심각도·기회 손실)으로 채웁니다. 정성 근거는 고객 인터뷰·VOC·합성사용자 인터뷰·CRO/BIAS 체크리스트를 씁니다
3. **Uplift 시뮬레이션** — 입력값만 답하면 스킬이 직접 계산합니다. 보수/기본/낙관 3시나리오로, 잔여 퍼널을 통과한 **최종 KPI 증분 금액**까지 — 이 숫자가 Impact의 근거가 됩니다
4. **Target 확정** — 벤치마크 / MDE 근사 / 내부 Gap 3법 중 하나로, 산출 근거 한 줄과 함께
5. **대안 솔루션 + Rationale** — 근거 7유형(경쟁사 UX·공개 레퍼런스·UT/인터뷰·과거 경험/지식/데이터·연구 논문·합성소비자 UT·BIAS 체크)으로 Confidence 근거를 쌓습니다
6. **ICE 재산정** — 본인이 먼저 점수를 매기고, 스킬이 근거 기반 제안을 전후 대조표로 냅니다 (팀 확정은 사람이 합니다)
7. **노션 착지** — 실험설계서 페이지에 붙여넣을 갱신 블록과 속성 변경 안내를 출력합니다

**인터뷰 지원** (수행 모드 안의 선택 서브플로우) — 실제 유저 인터뷰는 스킬이 대신할 수 없으니 앞뒤를 돕습니다:

1. **타겟 선정** — 가설의 문제·솔루션을 바탕으로 누구를 만나야 하는지, 스크리닝 질문까지
2. **스크립트 초안** — 유도 질문 없이 경험부터 묻는 인터뷰 스크립트 (문제 검증용 / 솔루션 UT용)
3. **transcript 분석** — 인터뷰 후 전사를 붙여넣으면 근거 발화를 추출해 그루밍 근거로 정리합니다 (가설에 불리한 반증도 숨기지 않습니다)

**리뷰 모드** (코치용) — "그루밍 리뷰"라고 말하면 진입: 19항목 체크리스트 판정(Critical/Recommended/Optional) + 품질 점수 + A~D 등급 + 보완 가이드.

## 시작하기

클로드에게 이렇게 말하세요:

- "가설 그루밍 시작" / "이 가설 그루밍해줘" — 수행 모드
- "업리프트 계산하자" / "Target 잡자" — 해당 단계로
- "그루밍 리뷰" — 코치용 리뷰 모드

그다음 **노션 가설 페이지 본문을 붙여넣으면** 됩니다.

## 이 플러그인이 하지 않는 것

- 샘플사이즈·실험 기간·MDE 정밀 계산, Variant 문구안, 지표 3층 확정, 실험 설계서 → **실험 설계 소관**
- 새 가설 작성 → `cro-hypothesis-backlog`
- 문제정의·BIAS 재진단 → `cro-problem-definition`
- ICE 곱셈·평균, 점수 확정, 근거 없는 수치 생성 → 하지 않습니다
